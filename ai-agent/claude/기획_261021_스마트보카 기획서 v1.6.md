## 2. 추진 배경 및 문제 정의

### 2.1 배경
- 토익은 대학생의 졸업 요건과 취업 준비에 널리 쓰이는 시험이고, 점수를 올리는 데는 어휘력이 기본이 된다.
- 종이 단어장이나 일반 단어장 앱은 **매일 얼마만큼 외울지**, **무엇을 다시 볼지**를 학습자가 직접 정해야 한다.

## 6. 핵심 기능 및 학습 흐름

### 6.1 전체 흐름

```
[프로그램 실행] → [학습 기록 불러오기] → [메인 화면]
   ├─ 일차 학습: [오늘 일차] → [암기: 1개씩 카드 넘기기] → (모든 단어를 봄)
   │             → [시험 활성화] → [시험 응시·채점] → [오답 기록] → [다음 일차 개방]
   ├─ 복습 학습: [지난 일차 선택] → [암기 카드로 다시 보기]
   ├─ 오답 학습: [오답 단어 목록(오답 횟수 많은 순)] → [암기 카드로 다시 보기]
   │             → [오답 시험] → (연속 3회 정답이면 오답 목록에서 제외)
   └─ 단어 목록 불러오기·저장
```

### 6.2 진도 생성 규칙 (SC-03)

| 구분 | 규칙 |
|------|------|
| 배정 방식 | CSV 순서대로 일차마다 신규 단어 **20개씩** 배정한다 (고정값, 사용자가 바꿀 수 없음) |
| 중복 금지 | 한 단어는 한 일차에만 속한다. 일차 사이에 같은 단어가 나오지 않는다 |
| 일차 수 | 2,000개 ÷ 20 = **100일차**. 나누어떨어지지 않으면 마지막 일차는 남은 단어로 구성한다 |
| 복습·오답 | 일차에 섞지 않는다. 복습 학습(§6.5)과 오답 학습(§6.6)에서 따로 다룬다 |

- 예시: 1일차는 1~20번 단어, 2일차는 21~40번 단어 … 100일차는 1,981~2,000번 단어.

### 6.3 일차 학습 – 암기 (SC-04)
- 한 화면에 단어 카드 1장(영단어와 그 뜻)을 보여 주고 '다음' / '이전'으로 넘긴다.
- 뜻은 CSV 뜻 칸의 내용을 **가공하지 않고 그대로** 보여 준다. 예를 들어 뜻 칸이 '문제, 쟁점; 발행하다'이면 전부 보여 준다.
- 그 일차의 20개 단어를 모두 한 번씩 보면 '암기 완료'로 표시하고 시험 버튼을 활성화한다.
- 하루에 여러 일차를 진행해도 된다. 실제 날짜가 아니라 **완료 여부**로 다음 일차를 연다.

### 6.4 일차 시험 (SC-05)
- 시험 범위: 해당 일차의 단어 20개
- 문제 형식: 영단어를 보여 주고 뜻을 4개 보기 중에서 고르는 **객관식 4지선다**
  - 정답 보기와 오답 보기 모두 CSV 뜻 칸 전체를 그대로 쓴다. 오답 보기 3개는 전체 단어장에서 다른 단어의 뜻 칸을 무작위로 뽑는다.
  - 뜻이 길면 보기 문장도 길어지므로, 보기가 잘리지 않도록 UI에서 줄바꿈을 지원한다.
  - 문제 순서는 무작위로 섞는다.
- 채점 결과(맞은 수 / 전체)를 보여 주고, 틀린 단어는 오답 횟수를 +1 하고 오답 목록에 올린다.
- 점수와 관계없이 시험을 마치면 그 일차를 '완료'로 표시하고 다음 일차를 연다.
- 이미 완료한 일차의 시험도 다시 볼 수 있다. 재시험에서 틀린 단어도 오답 목록에 올린다.

### 6.5 복습 학습 (SC-06)
- 이미 학습한 일차 중에서 하나를 골라 그 일차의 단어를 암기 카드 방식으로 다시 본다.
- 일차 진도(현재 일차, 완료 여부)에는 영향을 주지 않는다.
- 복습 학습에는 별도 시험을 두지 않는다. 지난 일차를 시험 보고 싶으면 일차 시험을 다시 보면 된다(§6.4).

### 6.6 오답 학습 (SC-07)
- 지금까지 시험에서 틀린 단어를 모아 오답 횟수가 많은 순서대로 암기 카드 방식으로 보여 준다.
- 오답 학습을 마치면 오답 단어로 **오답 시험**을 볼 수 있다. 문제 형식은 일차 시험과 같다.
- 단어마다 **연속 정답 횟수**를 기록한다.
  - 맞히면 연속 정답 횟수를 1 늘리고, **3이 되면 오답 목록에서 뺀다.**
  - 틀리면 연속 정답 횟수를 0으로 되돌리고 오답 횟수를 1 늘린다.
  - 일차 시험에서 다시 틀리면 그 단어는 오답 목록에 다시 올라간다.
- 오답 목록은 CSV로 내보낼 수 있다 (BR-06).

### 6.7 단어 목록 불러오기·저장 (SC-01)
- **불러오기**: 사용자가 고른 CSV 파일을 단어장으로 읽어 들인다.
- **저장(내보내기)**: 현재 단어장과 오답 목록을 각각 CSV로 저장한다.
- 다른 단어장을 불러왔을 때 기존 학습 기록을 어떻게 처리할지는 설계 단계에서 정한다.

## 7. 데이터

| 항목 | 내용 |
|------|------|
| 기본 데이터 | 토익 빈출 영단어와 뜻 2,000개. 파일은 `data/toeic_words_2000.csv` (2026-10-21 Claude 작성, 사용자 검수 예정) |
| 인코딩 | UTF-8 BOM (`utf-8-sig`). 엑셀에서 열어도 한글이 깨지지 않게 하기 위함. 프로그램은 `utf-8-sig`로 읽어 BOM 유무와 관계없이 처리한다 |
| 열 구성 | 헤더 `word,meaning`. 한 줄에 영단어 1개와 뜻 칸 1개. 뜻 안의 쉼표는 CSV 규칙에 따라 큰따옴표로 감싼다 |
| 뜻 표기 규칙 | 품사를 `[명]` `[동]` `[형]` `[부]` `[전]` `[접]`으로 표시한다. 같은 품사 안의 뜻은 `,`로, 뜻 묶음 사이는 `;`로 나눈다. 자주 쓰는 표현은 괄호로 덧붙인다. 예: `[명] 문제, 쟁점; (잡지의) 호 [동] 발행하다, 발급하다` |
| 단어 순서 | CSV 순서가 곧 일차 순서다. 주제별(사무, 인사, 마케팅, 재무, 제조, 물류·계약, 여행·행사, 회의, 시설·생활, 일반 빈출, 고급 어휘) 11개 묶음 순서로 배열했다 |
| 품질 조건 | 2,000행, 영단어 중복 없음(대소문자 무시), 빈 칸 없음, 가장 긴 뜻 51자 (2026-10-21 검증) |
| 원본 관리 | 주제별 원본 `ai-agent/claude/261021_토익단어2000/data/*.tsv` 를 고친 뒤 `script/build_csv.py` 로 CSV를 다시 만든다. 프로그램은 CSV를 직접 덮어쓰지 않는다 |
| 학습 기록 | 현재 일차, 일차별 암기·시험 완료 여부, 단어별 오답 횟수와 연속 정답 횟수(오답 시험). 저장 방식(JSON / SQLite)은 설계 단계에서 정한다 |
| 개인정보 | 다루지 않음 (로컬 단일 사용자) |

> 단어 뜻은 Claude가 작성한 것으로 공인 사전·기출 통계와 대조하지 않았다. 사용자 검수 후 수정 사항은 원본 TSV에 반영한다.

## 8. 기술 스택 후보 및 결정 (결정 기록)

### 8.1 배경
요청 내용상 Windows에서 개발한다는 점은 정해져 있다. 하지만 결과물을 **Windows 데스크톱 프로그램(Python/PyQt)** 과 **Android 앱(Kotlin)** 중 무엇으로 할지는 아직 정해지지 않았다.

### 8.2 대안 비교

| 항목 | A. Python + PyQt (Windows) | B. Kotlin (Android) |
|------|----------------------------|---------------------|
| 개발 환경 구성 | 쉬움 (Python, `pip install PyQt6`) | Android Studio, SDK, 에뮬레이터가 필요해 무거움 |
| CSV 처리 | 표준 라이브러리 `csv`로 간단함 | assets와 파일 접근 권한 처리가 필요함 |
| 파일 불러오기·저장(BR-06) | `QFileDialog`로 바로 구현 가능 | SAF(Storage Access Framework)를 써야 해서 상대적으로 복잡함 |
| 사용성 | PC 앞에서만 학습 가능 | 이동 중에도 학습 가능 (단어 앱에 더 어울림) |
| 테스트 | `pytest`로 로직을 단위 테스트하기 쉬움 | JUnit과 에뮬레이터가 필요함 |
| 배포 | PyInstaller로 exe 생성 | APK 빌드 |

### 8.3 결정 근거 (권고)
- **권고안: A. Python + PyQt**
  - 진도 생성, 시험 채점, 오답 집계 로직을 Python에서 가장 빠르게 구현하고 검증할 수 있다.
  - 파일 불러오기·저장 요구사항(BR-06)이 데스크톱 환경에서 훨씬 자연스럽다.
  - 로직을 UI와 분리해 두면 나중에 Kotlin으로 옮길 때 로직 설계를 그대로 다시 쓸 수 있다.
- **최종 결정 (2026-10-21)**: **A. Python + PyQt로 Windows 데스크톱 프로그램을 개발한다.** Python과 PyQt의 세부 버전(PyQt5/PyQt6)은 설계 단계의 결정 기록에서 정한다.

## 10. 성공 기준 및 확장 아이디어

### 10.1 성공 기준
- 기본 CSV 2,000개를 불러와 1~100일차 진도가 단어 중복 없이 만들어진다.
- 1일차 암기를 끝내면 시험이 활성화되고, 채점과 오답 기록이 저장된다.
- 복습 학습에서 지난 일차를 골라 다시 볼 수 있고, 오답 학습에서 오답 단어가 오답 횟수 순으로 나온다.
- 오답 시험에서 연속 3회 맞힌 단어가 오답 목록에서 빠진다.
- 프로그램을 다시 실행해도 진도와 오답 기록이 그대로 복원된다.
- 진도 생성과 오답 집계 로직에 대한 단위 테스트를 통과한다.

### 10.2 확장 아이디어 (이번 범위 외)
- 간격 반복(SRS, 예: 1·3·7일 뒤 복습) 기반 복습 추천
- 뜻을 보고 영단어를 입력하는 주관식 시험, 철자 시험
- 학습 통계 화면 (일차별 정답률, 취약 단어 순위)
- TTS 발음 듣기
