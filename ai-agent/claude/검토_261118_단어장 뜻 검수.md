## 2. 형식 검수 결과 — 이상 없음

- 2,000개 모두 `[품사]` 로 시작한다. 품사 분포: 명 1,127 / 동 680 / 형 445 / 부 100 / 전 4 / 접 2 (한 단어에 품사가 여럿이면 각각 셈)

- 뜻에 영문이 들어간 30개는 모두 `(for)`, `(-s)`, `(keynote speech: 기조연설)` 같은 의도된 전치사·용례 표기다.
- `build_csv.py` 로 원본에서 다시 만든 CSV 가 현재 `data/toeic_words_2000.csv` 와 바이트 단위로 같다.

## 4. 검토했으나 그대로 두는 항목

토익에서 실제로 쓰이는 뜻이라 유지한다: facility(재능), draft(어음), policy(보험 증권), capacity(자격),
hire [명](신입 사원), honor(약속을 지키다), debit [동](인출하다), pending [전](~까지), appropriate [동](책정하다),
headline [동](주연을 맡다), cover(대신 일하다), engage(고용하다), solicit(간청하다, 요청하다).

## 5. 수정 영향

- 학습 기록의 키는 영단어(ADR-07)이므로 뜻만 바꾸면 기존 `userdata/progress.json` 은 그대로 이어진다.
- 단어 수·순서·일차 배정은 바뀌지 않는다.
- 수정 절차: 원본 TSV 수정 → `script/build_csv.py` 로 CSV 재생성 → `pytest` 실행.

## 6. 한계

- Claude 의 검수는 사전 대조가 아니라 지식에 기댄 판단이다. 토익 교재와 대조한 것은 아니다.
- 뜻이 "틀리지 않은" 수준에서 더 나은 번역이 있을 수 있는 항목까지 모두 찾았다고 보장하지 못한다.
