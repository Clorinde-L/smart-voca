## 문제
SC-01~08 범위 항목이 화면·모듈 단위로 분해되지 않아 구현 순서와 테스트 단위를 정할 수 없음.

## 영향 범위
- 산출물: `ai-agent/claude/설계_yymmdd_기능 분해도 v1.0.md`
- 입력: 요구사항 명세서(A-1)
- 이후 프로세스 설계서(D-3), UI/UX 설계서(D-4), 모듈 구조(D-5)의 기준이 됨

## 기대 결과
- 시스템 → 대기능(단어 데이터 / 진도 / 일차 학습 / 일차 시험 / 복습 / 오답 / 기록 저장) → 단위 기능 3단계 계층 분해.
- 단위 기능마다 ID(`F-xx-yy`)와 대응 FR 명시.
- 단위 기능 수준에서 UI 기능과 로직 기능을 구분 표시 (로직/UI 분리 방침, 기획서 §8.3).
