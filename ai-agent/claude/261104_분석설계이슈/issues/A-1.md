## 문제
기획서 v1.6 의 BR-01~07, SC-01~08 은 비즈니스 수준 요구사항. 구현·테스트에 바로 쓸 기능/비기능 요구사항 ID 가 없음.

## 영향 범위
- 산출물: `ai-agent/claude/분석_yymmdd_요구사항 명세서 v1.0.md` (승인 후 `docs/`)
- 입력: 기획서 §3 BRD, §5 SS, §6 핵심 기능, §9 가정·제약
- 이후 모든 설계 문서와 테스트 정의서가 이 ID 를 참조함 (방법론 §3.1 추적성)

## 기대 결과
- 기능 요구사항 `FR-xx`, 비기능 요구사항 `NFR-xx` 를 기능별로 명세. 각 항목에 수용 기준 포함.
- 추적 매트릭스 `P → BR → SC → FR/NFR` 작성.
- 기획서 §6.7 의 미결 사항(다른 단어장 불러올 때 기존 기록 처리)을 요구사항으로 확정.
