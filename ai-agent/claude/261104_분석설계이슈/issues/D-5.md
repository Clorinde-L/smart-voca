## 문제
단일 데스크톱 프로그램이라 아키텍처·인터페이스 정의서는 간략화 대상(기획서 §12). 그러나 로직/UI 분리 방침(§8.3)을 지키려면 모듈 구조와 모듈 간 호출 규약은 정해야 함.

## 영향 범위
- 산출물: `ai-agent/claude/설계_yymmdd_시스템 구조 v1.0.md` (방법론 §2.3 아키텍처 설계서 + 인터페이스 정의서 통합 간략본)
- 입력: 기능 분해도(D-1), 데이터 설계서(D-2), 프로세스 설계서(D-3), UI/UX 설계서(D-4)
- 관련 디렉토리: `src/` 패키지 구조

## 기대 결과
- 계층 구조 확정: 데이터 접근(CSV·기록 저장) / 도메인 로직(진도·시험·오답) / UI(PyQt). 각 계층의 패키지·모듈 파일명 명시.
- 계층 간 인터페이스(공개 함수·클래스 시그니처, 데이터 전달 객체) 정의. UI 가 로직을 호출하는 방향만 허용.
- 실행 진입점, 설정·데이터 파일 경로 규칙, PyInstaller 배포 시 경로 처리 방침 포함.
