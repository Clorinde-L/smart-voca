## 문제
진도 생성, 4지선다 출제, 채점·오답 집계, 연속 3회 정답 제외 규칙이 기획서에 산문으로만 있음. 단위 테스트 가능한 알고리즘 명세가 필요함.

## 영향 범위
- 산출물: `ai-agent/claude/설계_yymmdd_프로세스 설계서 v1.0.md`
- 입력: 기획서 §6.2~6.6, 기능 분해도(D-1), 데이터 설계서(D-2)
- 이후 로직 모듈 구현과 테스트 정의서(BDD 시나리오)의 직접 입력

## 기대 결과
- 알고리즘별 입력 / 처리 / 출력 / 예외 명세: 진도 생성(20개 고정, 마지막 일차 처리), 출제(오답 보기 3개 무작위 추출·중복 뜻 회피·문제 섞기), 채점·오답 집계, 오답 시험 연속 정답 처리, 일차 완료·개방 판정.
- 각 알고리즘에 BDD 형식(Given/When/Then) 시나리오 2개 이상 첨부.
- 로직 함수 시그니처 수준(함수명·인자·반환)까지 명시. 소스 코드는 붙이지 않음.
