## 문제
PyQt 화면 구성과 화면 간 이동 흐름이 정의되지 않음. 뜻이 길 때 보기 줄바꿈(기획서 §6.4) 등 UI 제약도 화면 수준으로 구체화 필요.

## 영향 범위
- 산출물: `ai-agent/claude/설계_yymmdd_UI UX 설계서 v1.0.md`
- 입력: 기획서 §6.1 전체 흐름, 기능 분해도(D-1), 현황·환경 분석서(A-2)
- 이후 PyQt 위젯 구현의 기준

## 기대 결과
- 화면 목록: 메인, 일차 학습(카드), 일차 시험, 시험 결과, 복습 일차 선택, 오답 학습, 오답 시험, 단어장 불러오기·저장.
- 화면별 와이어프레임(텍스트 또는 그림)과 요소·동작 표, 화면 전이도(Storyboard).
- 긴 뜻 줄바꿈, 시험 버튼 활성화 조건 표시, 진도 표시 방식 등 UI 규칙 명세.
