## 2. 기획서 대비 추가 확정 사항

기획서에서 설계 단계로 넘기거나 명시하지 않은 동작을 요구사항 수준에서 확정한다. **사용자 검토가 필요한 결정**이다.

### 2.1 D-01 다른 단어장을 불러올 때 기존 학습 기록 처리 (기획서 §6.7 미결)

- **배경**: 학습 기록(일차 완료 여부, 오답 횟수)은 단어장의 단어 순서·구성에 묶여 있다. 단어장이 바뀌면 "3일차 완료" 같은 기록이 가리키는 단어가 달라진다.
- **대안**
  - (a) 확인 후 기록 초기화: 새 단어장은 1일차부터 다시 시작한다.
  - (b) 단어장별 기록 분리 보관: 단어장마다 기록을 따로 두고 전환할 때 복원한다.
  - (c) 단어 일치 기준 승계: 같은 영단어의 오답 기록만 새 단어장으로 옮긴다.
- **결정 근거**: **(a) 채택.** 구현과 테스트가 가장 단순하고, 기록과 단어장이 어긋날 여지가 없다. (b) 는 단어장 식별·목록 관리 기능이 추가로 필요해 범위가 커지고, (c) 는 일차 진도는 어차피 옮길 수 없어 기록이 반쪽만 남는다. 기록 손실 위험은 교체 전 확인 대화상자와 오답 목록 내보내기 안내로 줄인다. → FR-04

### 2.2 그 밖의 명시 사항

| ID | 내용 | 근거 | 반영 |
|----|------|------|------|

## 3. 기능 요구사항 (FR)

### 3.1 단어 데이터 관리 (SC-01)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-01 | **기본 단어장 로드** — 사용자가 불러온 단어장이 없으면 기본 단어장을 `utf-8-sig` 로 읽어 단어장으로 쓴다. | 첫 실행 시 2,000 단어가 CSV 순서대로 로드된다. BOM 이 없는 UTF-8 파일도 같은 결과로 읽힌다. |
| FR-02 | **CSV 형식 검증** — 단어장으로 읽는 모든 CSV 에 대해 헤더(`word,meaning`), 빈 칸, 영단어 중복(대소문자 무시), 최소 크기(단어 4개 이상·서로 다른 뜻 4개 이상)를 검사한다. | 조건을 어긴 파일은 불러오지 않고, 어긴 조건과 행 번호를 알려 준다. 기존 단어장과 학습 기록은 그대로다. |
| FR-03 | **단어장 불러오기** — 사용자가 파일 선택 대화상자에서 고른 CSV 를 검증(FR-02)한 뒤 현재 단어장으로 교체한다. 교체한 단어장은 프로그램을 다시 실행해도 유지된다. | 검증을 통과한 CSV 를 불러오면 진도가 그 단어장 기준으로 다시 만들어진다(FR-07). 재실행 후에도 같은 단어장이 열린다. 원본 CSV 와 `data/toeic_words_2000.csv` 는 수정되지 않는다. |
| FR-04 | **단어장 교체 시 기록 초기화** — 단어장을 교체하기 전에 학습 기록이 지워진다는 확인을 받고, 승인하면 진도·오답 기록을 모두 초기화한다. | 확인 대화상자에서 취소하면 단어장과 기록이 그대로다. 승인하면 1일차만 열린 초기 상태가 되고 오답 목록이 빈다. 대화상자에 오답 목록 내보내기(FR-06) 안내가 있다. |
| FR-05 | **단어장 내보내기** — 현재 단어장을 사용자가 지정한 경로에 CSV(`word,meaning`, `utf-8-sig`)로 저장한다. | 내보낸 파일을 다시 불러오면(FR-03) 단어 수·순서·뜻이 원래와 같다. |
| FR-06 | **오답 목록 내보내기** — 현재 오답 목록을 사용자가 지정한 경로에 CSV 로 저장한다. 열은 영단어, 뜻, 오답 횟수이며 순서는 FR-22 와 같다. | 오답 목록의 단어 수와 내보낸 행 수가 같다. 오답 목록이 비어 있으면 내보내지 않고 안내한다. |

### 3.2 진도 생성 (SC-03)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-07 | **일차 편성** — 단어장을 CSV 순서대로 20개씩 나눠 1일차부터 차례로 배정한다. 20 으로 나누어떨어지지 않으면 마지막 일차는 남은 단어로 구성한다. | 2,000 단어 → 100일차, 1일차는 1~20번·100일차는 1,981~2,000번 단어. 2,010 단어 → 101일차(마지막 10개). 모든 단어가 정확히 한 일차에만 속한다. |
| FR-08 | **일차 상태와 개방** — 일차마다 `잠김 / 학습 가능 / 암기 완료 / 완료` 상태를 관리한다. 1일차는 처음부터 학습 가능이고, N일차가 완료되면 N+1일차가 학습 가능이 된다. 개방은 날짜가 아니라 완료 여부로만 정한다. | 초기 상태에서 1일차만 열려 있다. 1일차 시험을 제출하면 2일차가 열린다. 같은 날 여러 일차를 연달아 진행할 수 있다. 마지막 일차 완료 후에는 더 열 일차가 없음을 알린다. |
| FR-09 | **진도 현황 표시** — 메인 화면에 현재 일차, 전체 일차 수, 완료한 일차 수, 오답 목록의 단어 수를 보여 준다. | 표시 값이 저장된 학습 기록과 일치한다. 시험 제출 직후 메인 화면으로 돌아오면 값이 갱신되어 있다. |

### 3.3 일차 학습 – 암기 (SC-04)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-10 | **암기 카드 표시** — 한 화면에 카드 1장(영단어, 뜻, 현재 위치 `n / 전체`)을 보여 준다. 뜻은 CSV 뜻 칸을 가공하지 않고 그대로 표시한다. | 뜻 칸이 `[명] 문제, 쟁점; (잡지의) 호 [동] 발행하다, 발급하다` 이면 그 문자열 전체가 보인다. |
| FR-11 | **카드 이동** — '다음' / '이전'으로 카드를 넘긴다. | 첫 카드에서는 '이전', 마지막 카드에서는 '다음'을 쓸 수 없다. 카드 순서는 단어장 순서와 같다. |
| FR-12 | **암기 완료 판정** — 일차의 모든 카드를 한 번 이상 표시하면 그 일차를 암기 완료로 기록하고 시험 버튼을 활성화한다. 도중에 나가면 본 카드 진행은 저장하지 않는다. | 20장 중 19장만 보면 시험 버튼이 비활성이다. 20장째를 표시하는 순간 활성화되고, 재실행 후에도 암기 완료 상태가 유지된다. 도중에 나갔다 들어오면 첫 카드부터 시작한다. |

### 3.4 일차 시험 (SC-05)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-13 | **응시 조건** — 암기 완료 이상인 일차만 시험을 볼 수 있다. | 학습 가능(암기 미완료) 일차와 잠긴 일차에서는 시험을 시작할 수 없다. |
| FR-14 | **문제 생성** — 대상 단어마다 4지선다 문제 1개를 만든다. 문제는 영단어, 보기는 뜻 칸 전체다. 오답 보기 3개는 단어장 전체에서 다른 단어의 뜻을 무작위로 뽑으며, 4개 보기의 뜻은 서로 달라야 한다. 문제 순서와 보기 위치는 무작위다. | 20 단어 일차 → 20문제, 단어가 한 번씩만 출제된다. 모든 문제에 정답 보기가 정확히 1개 있고 보기 4개가 서로 다르다. 같은 난수 시드를 주면 같은 시험지가 만들어진다(NFR-04). |
| FR-15 | **응시 진행** — 문제를 한 개씩 보여 주고 보기 하나를 고르게 한다. 모든 문제에 답해야 제출할 수 있다. 도중에 나가면 그 시험은 반영하지 않는다. | 답하지 않은 문제가 있으면 제출할 수 없다. 도중에 나가면 일차 상태·오답 횟수·오답 목록이 바뀌지 않는다. |
| FR-16 | **채점 결과 표시** — 제출하면 맞은 수 / 전체 문제 수와 틀린 단어 목록(영단어, 정답 뜻, 고른 뜻)을 보여 준다. | 20문제 중 3개를 틀리면 `17 / 20` 과 틀린 단어 3개가 표시된다. |
| FR-17 | **오답 기록** — 틀린 단어마다 오답 횟수를 1 늘리고 연속 정답 횟수를 0 으로 되돌린 뒤 오답 목록에 올린다. 맞힌 단어의 기록은 바꾸지 않는다. | 처음 틀린 단어: 오답 횟수 1, 오답 목록에 등재. 이미 목록에 있던 단어를 또 틀리면 오답 횟수만 늘고 중복 등재되지 않는다. |
| FR-18 | **일차 완료 처리** — 시험을 제출하면 점수와 관계없이 그 일차를 완료로 기록하고 다음 일차를 연다(FR-08). | 0점으로 제출해도 일차가 완료되고 다음 일차가 열린다. |
| FR-19 | **재시험** — 완료한 일차의 시험을 다시 볼 수 있다. 오답 기록(FR-17)은 같은 방식으로 반영하고, 일차 상태는 완료를 유지한다. | 완료한 1일차를 재시험해 2개를 틀리면 두 단어의 오답 횟수가 1씩 늘어난다. 문제 순서는 시험마다 새로 섞인다. |

### 3.5 복습 학습 (SC-06)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-20 | **복습 일차 선택** — 암기 완료 이상인 일차 목록에서 하나를 고른다. | 잠긴 일차와 암기 미완료 일차는 목록에 없다. 대상 일차가 없으면 안내 문구를 보여 준다. |
| FR-21 | **복습 카드 학습** — 고른 일차의 단어를 암기 카드 방식(FR-10, FR-11)으로 다시 본다. 학습 기록은 바꾸지 않으며 시험은 제공하지 않는다. | 복습 전후로 일차 상태·오답 횟수·오답 목록이 같다. 복습 화면에 시험 버튼이 없다. |

### 3.6 오답 학습·오답 시험 (SC-07)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-22 | **오답 목록 조회** — 오답 목록을 오답 횟수가 많은 순으로 보여 준다. 횟수가 같으면 단어장 순서를 따른다. | 오답 횟수가 3, 1, 2 인 단어는 3 → 2 → 1 순으로 나온다. 목록이 비어 있으면 안내 문구를 보여 주고 오답 학습·시험을 시작할 수 없다. |
| FR-23 | **오답 카드 학습** — 오답 목록의 단어를 FR-22 순서대로 암기 카드 방식(FR-10, FR-11)으로 보여 준다. | 카드 수가 오답 목록의 단어 수와 같다. |
| FR-24 | **오답 시험** — 오답 카드를 모두 한 번 이상 보면 오답 시험을 볼 수 있다. 대상은 그 시점의 오답 목록 전체이고, 문제 형식과 진행은 일차 시험과 같다(FR-14, FR-15, FR-16). | 오답 단어가 1개뿐이어도 4지선다 1문제가 만들어진다(오답 보기는 단어장 전체에서 뽑는다). 카드를 다 보기 전에는 시험 버튼이 비활성이다. |
| FR-25 | **오답 시험 결과 반영** — 맞힌 단어는 연속 정답 횟수를 1 늘리고, 3 이 되면 오답 목록에서 뺀다. 틀린 단어는 연속 정답 횟수를 0 으로 되돌리고 오답 횟수를 1 늘린다. 목록에서 빠져도 누적 오답 횟수는 유지한다. | 같은 단어를 오답 시험에서 3번 연속 맞히면 목록에서 사라진다. 2번 맞히고 1번 틀리면 연속 정답 횟수가 0 이 되고 목록에 남는다. 빠진 단어를 일차 시험에서 다시 틀리면 연속 정답 횟수 0 으로 다시 등재된다. |

### 3.7 학습 기록 저장 (SC-08)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-26 | **자동 저장** — 암기 완료, 일차 시험 제출, 오답 시험 제출, 단어장 교체 시점에 학습 기록(일차별 암기·시험 완료 여부, 단어별 오답 횟수·연속 정답 횟수·오답 목록 등재 여부)을 사용자 조작 없이 저장한다. | 시험 제출 직후 프로그램을 강제 종료하고 다시 실행해도 그 시험 결과가 남아 있다. '저장' 버튼이 따로 없다. |

| FR-28 | **기록 없음·손상 처리** — 기록이 없으면 초기 상태(기본 단어장, 1일차만 열림)로 시작한다. 기록을 읽을 수 없으면 사용자에게 알리고, 손상된 파일을 따로 보존한 뒤 초기 상태로 시작한다. | 기록 파일을 지우고 실행하면 오류 없이 초기 상태로 시작한다. 내용을 깨뜨린 기록 파일로 실행해도 프로그램이 종료되지 않고, 손상 파일이 다른 이름으로 남아 있다. |
