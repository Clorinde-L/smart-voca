## 1. 배경과 범위

교수님이 스마트 보카를 웹으로 구현하라고 하셨다(2026-11-25). 사용자와 정한 범위는 다음과 같다.

| 항목 | 결정 |
|------|------|
| 웹 범위 | **내 PC 브라우저에서 실행.** `python -m smartvoca` 가 로컬 서버(127.0.0.1)를 띄우고 브라우저를 연다. 사용자 1명, 기록은 지금처럼 `userdata/` |
| 화면 기술 | **Flask + Jinja2 HTML 템플릿.** 서버가 HTML 을 만들어 보내고, 단축키·자동 넘김·확인 대화상자에만 JS 를 조금 쓴다 |
| PyQt | **웹으로 완전히 교체.** `src/smartvoca/ui/`, `tests/test_ui_flow.py`, PyQt6 의존성을 지운다 |

로직 계층(`core`, `storage`, `session.py`)은 고치지 않는다. 화면이 `AppSession` 만 부르게 해 둔 구조(ADR-05) 덕분에 UI 계층만 바꾸면 된다.

## 2. 결정 기록 초안 (승인 후 `docs/설계_261111_결정 기록.md` 에 옮김)

### ADR-18 화면을 PyQt6 데스크톱에서 로컬 Flask 웹으로 교체 (ADR-01 대체)

- **배경**: 교수님 요청으로 웹 구현이 필요해졌다. 기존 ADR-01 은 PyQt6 를 택했다.
- **대안**: (a) 인터넷 배포·여러 사용자, (b) 서버 없는 정적 페이지(localStorage), (c) 내 PC 에서 도는 로컬 웹 서버.
- **결정 근거**: **(c) 채택.** (a) 는 로그인·사용자별 저장·호스팅이 필요하고 오프라인(NFR-02)·개인정보(NFR-09) 요구사항을 다시 써야 한다. (b) 는 로직을 JavaScript 로 다시 짜야 해 Python 로직과 테스트 147개를 버리게 된다. (c) 는 로직·저장 계층과 요구사항을 그대로 두고 화면만 바꾼다.
- **영향**: 서버는 `127.0.0.1` 에만 연다(다른 PC 에서 접속 불가). NFR-01 의 "Python + PyQt 데스크톱"을 "Python + Flask, 브라우저"로 고친다.

### ADR-19 화면 기술은 Flask + 서버 렌더링 템플릿

- **배경**: 웹 화면을 만드는 방식을 정해야 한다.
- **대안**: (a) Flask + Jinja2 템플릿(서버 렌더링), (b) FastAPI JSON API + JS 화면, (c) NiceGUI 같은 Python 전용 웹 UI.
- **결정 근거**: **(a) 채택.** 요청·응답·폼·리다이렉트라는 웹의 기본 구조가 코드에 그대로 드러나 배우기 좋고, JS 가 적어 화면 로직이 서버(Python)에 남는다. 모든 판단(카드를 다 봤는가, 제출할 수 있는가)을 서버가 하므로 "화면은 판단하지 않음" 원칙(UI/UX 설계서 §1.1)과도 맞는다.
- **영향**: 카드 넘기기·문제 이동마다 페이지를 새로 받는다(로컬이라 수 ms). 진행 중인 카드 묶음·시험지는 서버 메모리(`WebState`)에 둔다.

### ADR-20 진행 중인 카드·시험은 서버 메모리에 하나만 둔다

- **배경**: 웹은 요청마다 끊기므로, 카드 위치·고른 답을 어딘가에 들고 있어야 한다.
- **대안**: (a) 서버 메모리의 `WebState` 하나, (b) 브라우저 쿠키·폼 숨김 칸, (c) 파일에 저장.
- **결정 근거**: **(a) 채택.** 사용자가 1명이고 서버가 내 PC 에만 있으므로 상태 하나면 충분하다. (b) 는 시험지의 정답 위치가 브라우저로 넘어가 답을 볼 수 있다. (c) 는 "도중에 나간 암기·시험은 저장하지 않음"(ADR-12)과 어긋난다.
- **영향**: 서버를 끄면 진행 중인 카드·시험은 사라진다(ADR-12 와 같은 결과). 탭을 두 개 열면 같은 상태를 공유한다. 서버는 한 번에 요청 하나만 처리(`threaded=False`)해 `AppSession` 을 동시에 건드리지 않는다.

## 3. 화면 대응 (UI/UX 설계서 S-01 ~ S-07, DL-01 ~ DL-05)

| ID | PyQt | 웹 (URL · 템플릿) | 바뀌는 점 |
|----|------|-------------------|-----------|
| S-01 | `HomePage` | `GET /` · `home.html` | 없음 |
| S-02 | `CardPage` | `GET /cards` · `cards.html`, 이동은 `POST /cards/next·prev` | 뜻 가리기 설정은 서버 메모리(재시작하면 꺼짐, UD-04 그대로) |
| S-03 | `ExamPage` | `GET /exam` · `exam.html`, `POST /exam/answer·goto·submit·abort` | 0.3초 자동 넘김은 JS 가 기다렸다가 폼을 보낸다 |
| S-04 | `ResultPage` | `GET /result` · `result.html` | 점수 고리는 SVG |
| S-05 | `DayListPage` | `GET /days` · `day_list.html` | 행을 고른 뒤 버튼 대신 **행마다 `복습`·`시험` 버튼** (웹에서 더 자연스러움) |
| S-06 | `WrongListPage` | `GET /wrong` · `wrong_list.html` | 없음 |
| S-07 | `WordbookPage` | `GET /wordbook?q=` · `wordbook.html` | 검색은 서버에서 거른다(Enter 로 검색) |
| DL-01 | 확인 상자 | `import_confirm.html` | 확인 페이지, `취소` 에 초점 |
| DL-02 | 오류 상자 | `import_confirm.html` (오류 모드) | 오류 목록 페이지 |
| DL-03 | 확인 상자 | `<dialog>` (JS) | `계속 풀기` 에 초점 |
| DL-04 | 알림 상자 | 화면 위 알림 띠 (flash) | — |
| DL-05 | 파일 상자 | `<input type=file>` 업로드 · 브라우저 다운로드 | 내보낸 파일은 브라우저 다운로드 폴더로 |

## 4. 파일 단위 계획

### 4.1 새로 만듦 — `src/smartvoca/web/`

| 파일 | 내용 |
|------|------|
| `__init__.py` | 패키지 표시 |
| `state.py` | `CardMode`, `CardStudy`(카드 묶음 + 모드 + 시험 잠금 해제 여부), `ExamMode`, `ExamRun`(시험지 + 고른 답 + 현재 위치 + 자동 넘김 규칙 `advance_after_answer`), `ResultView`, `PendingImport`, `WebState`. Flask 를 모르는 순수 Python |
| `wordsearch.py` | `day_of(word)`, `filter_words(words, query)` — S-07 검색 규칙 (PyQt 의 `WordFilterProxy` 를 옮김) |
| `app.py` | `create_app(session)` — Flask 앱 생성, 라우트(화면 전이도 §4 를 한 파일에), 외부 사이트의 POST 차단(Origin 검사) |
| `server.py` | `main()` — 세션 열기, 빈 포트 확인, 서버 시작, 브라우저 열기. 이미 실행 중이면 브라우저만 연다 |
| `templates/*.html` | `base`, `home`, `cards`, `exam`, `result`, `day_list`, `wrong_list`, `wordbook`, `import_confirm`, `fatal` |
| `static/style.css` | `ui/theme.py` 의 색·글꼴·간격을 CSS 변수로 옮김 |
| `static/app.js` | `data-key` 단축키, 시험 자동 넘김(0.3초), 시험 중단 `<dialog>` |

### 4.2 고침

| 파일 | 내용 |
|------|------|
| `src/smartvoca/__main__.py` | `smartvoca.web.server.main` 을 부름 |
| `pyproject.toml`, `requirements.txt` | PyQt6 → Flask. 템플릿·정적 파일을 패키지 데이터로 |
| `tests/test_architecture.py` | 검사 대상에서 `web` 을 빼고, 로직 계층이 Flask·web 을 import 하지 않는지 검사 |
| `스마트보카 실행.bat` | `pythonw` → `python` (콘솔 창을 닫으면 서버 종료) |
| `README.md` | 설치·실행·종료 방법 |

### 4.3 새 테스트

| 파일 | 내용 |
|------|------|
| `tests/test_web_state.py` | `ExamRun` 자동 넘김·제출 조건, `filter_words` |
