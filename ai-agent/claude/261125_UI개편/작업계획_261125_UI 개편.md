## 2. 결정 기록 초안 (승인 후 `docs/설계_261111_결정 기록.md` 로)

### ADR-21 일차 잠금 폐지 (FR-08 변경)

- **배경**: 지금은 N일차 시험을 내야 N+1일차가 열린다. 사용자는 일차 목록에서 원하는 일차를 골라 보고 싶어 한다(이미 아는 일차를 건너뛰거나, 시험 전 범위를 미리 보는 경우).
- **대안**: (a) 잠금 폐지, (b) 잠긴 일차는 미리보기만, (c) 잠금 유지.
- **결정 근거**: **(a).** 대학생 토익 준비는 시험 범위·약한 부분에 따라 순서를 바꾸는 일이 많다. 순서를 지키게 하는 대신 '오늘의 학습'에서 안 끝낸 가장 앞 일차를 추천해 기본 흐름은 유지한다. 응시 조건(카드를 다 봐야 시험, FR-12·FR-13)은 그대로 둔다.
- **영향**: `DayStatus.LOCKED` 를 없앤다. 상태는 `학습 전 / 암기 완료 / 완료` 셋. `core/schedule.py` 의 `day_status`, `session.complete_memorize` 의 잠김 검사를 고친다. 저장 형식(progress.json)은 바뀌지 않는다. FR-08, FR-18, FR-20, FR-21 을 고친다.

### ADR-22 일차 목록·일차 상세 화면과 공통 메뉴 막대 (ADR-11 확장)

- **배경**: 잠금이 없어지면 "지난 일차"(암기 완료 이상만)라는 구분이 의미를 잃는다. 메뉴로 가려면 매번 메인으로 돌아가야 했다.
- **대안**: (a) 일차 목록(전체) → 일차 상세(단어 20개, 학습·시험) 두 단계, (b) 목록 한 화면에 버튼만.
- **결정 근거**: **(a).** 상세 화면에서 그 일차의 단어를 먼저 훑어보고 학습·시험을 고를 수 있다. 복습과 첫 학습이 같은 카드 화면(일차 학습)으로 합쳐져 화면 모드가 줄어든다. 공통 메뉴 막대(홈·일차·오답 학습·단어 목록·테마)는 어느 화면에서든 한 번에 이동하게 한다. 시험 화면에서는 메뉴 막대를 숨겨 실수로 나가지 않게 한다.
- **영향**: S-05 를 "일차 목록"으로 바꾸고 S-08 "일차 상세"를 더한다. 카드의 복습 모드(REVIEW)를 없앤다 — 끝낸 일차를 다시 학습해도 기록은 바뀌지 않으므로(FR-12 는 '학습 전' 일차만 기록) 복습과 같다. 카드 화면에서도 시험 버튼이 보인다.

### ADR-23 어두운 테마

- **배경**: 밤에 공부할 때 밝은 화면이 눈부시다. UI/UX 설계서 §9 개선 후보에 있던 항목.
- **대안**: (a) 운영체제 설정을 따르고 메뉴 막대 버튼으로 자동/밝게/어둡게 전환, (b) 버튼 전환만.
- **결정 근거**: **(a).** 기본은 운영체제를 따라 따로 설정할 필요가 없고, 원하면 바꿀 수 있다. 선택은 브라우저(localStorage)에 기억한다 — 학습 기록이 아니라 보기 설정이라 progress.json 에 넣지 않는다.
- **영향**: 모든 색을 CSS 변수로 옮기고 어두운 값 묶음을 둔다.

### ADR-24 발음 듣기는 브라우저 내장 음성 합성

- **배경**: 단어를 눈으로만 외우면 듣기 파트에서 못 알아듣는다.
- **대안**: (a) 브라우저 Web Speech API(`speechSynthesis`), (b) 외부 발음 API, (c) 발음 파일 동봉.
- **결정 근거**: **(a).** 설치·파일이 필요 없다. Windows 에 기본으로 들어 있는 영어 음성(내 PC 음성)을 먼저 골라 인터넷 없이 동작한다(NFR-02). (b) 는 오프라인 요구사항에 어긋나고, (c) 는 2,109개 파일을 만들어야 한다.
- **영향**: 카드·일차 상세·시험 화면에 발음 버튼, 카드·시험에서 `P` 키. 음성이 없는 브라우저에서는 버튼을 숨긴다. 기계 음성이라 실제 발음과 조금 다를 수 있다.

## 3. 화면 구성 (개편 후)

| ID | 화면 | URL | 바뀌는 점 |
|----|------|-----|-----------|
| — | 메뉴 막대 | 모든 화면(시험 제외) | 새로 추가: 홈 / 일차 / 오답 학습(n) / 단어 목록 / 테마 버튼 |
| S-01 | 메인 | `/` | 오늘의 학습 + 현황 칸 + **일차 한눈에**(전체 일차를 작은 칸으로, 누르면 상세) |
| S-05 | 일차 목록 | `/days?show=` | 전체 일차 카드 격자. 상태 거르기 탭(전체/학습 전/암기 완료/완료) |
| S-08 | 일차 상세 | `/days/<n>` | 새로 추가: 단어 20개 표(발음 버튼), 카드로 학습, 시험 보기, 이전·다음 일차 이동 |
| S-02 | 카드 | `/cards` | 복습 모드 없앰, 발음 버튼, 뒤로 → 일차 상세 |
| S-03 | 시험 | `/exam` | 발음 버튼, 메뉴 막대 숨김 |
| S-04 | 결과 | `/result` | "다음 추천 일차" 버튼 (안 끝낸 가장 앞 일차) |
| S-07 | 단어 목록 | `/wordbook` | 일차 칸을 누르면 그 일차 상세로 |
