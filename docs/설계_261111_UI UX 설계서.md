### 1.1 설계 방향

| 방향 | 내용 | 근거 |
|------|------|------|
| 고민 없는 시작 | 메인 화면에서 가장 큰 버튼 하나로 오늘 할 일차를 바로 시작한다 | 기획서 §4 주요 기대, 현황·환경 분석서 I-01 |
| 한 화면 한 가지 | 카드 1장, 문제 1개만 크게 보여 준다 | FR-10, FR-15 |
| 조건을 눈에 보이게 | 시험 버튼이 왜 꺼져 있는지, 오답 단어가 언제 빠지는지 화면에 적는다 | 현황·환경 분석서 I-03 |
| 화면 부품 재사용 | 카드·시험·결과 화면을 하나씩만 만들고 모드로 구분한다 | 기능 분해도 §4 |
| 화면은 판단하지 않음 | 화면은 로직 함수를 부르고 결과를 그리기만 한다 | NFR-03 |

## 2. 결정 기록

UD-01 ~ UD-04 는 `설계_261111_결정 기록.md` 로 옮겼다(대응은 §11). 이 절은 화면 설계의 맥락을 위해 남기며, 결정이 바뀌면 결정 기록을 기준으로 고친다.

### 2.1 UD-01 시험 중 정오 표시 시점

- **배경**: 요구사항 명세서 §6 에서 문제별 즉시 정오 표시 여부를 UI 설계로 넘겼다.
- **대안**: (a) 답을 고를 때마다 바로 정오 표시, (b) 모두 답한 뒤 제출하면 한꺼번에 표시.
- **결정 근거**: **(b) 채택.** FR-15("모든 문제에 답해야 제출")와 맞고, 제출 전까지 이전 문제로 돌아가 답을 고칠 수 있어 실제 시험과 비슷하다. (a) 는 정답을 본 뒤 도중에 나가 다시 응시하면(D-04 에 따라 미반영) 답을 알고 시험을 보게 되어 채점의 의미가 약해진다.

### 2.2 UD-02 화면 전환 방식

- **배경**: 화면이 7개이고 전환이 잦다.
- **대안**: (a) 창 하나에서 화면만 교체(`QStackedWidget`), (b) 화면마다 새 창·대화상자.
- **결정 근거**: **(a) 채택.** 창이 여러 개 뜨면 "지금 어디인지"가 흐려지고 시험 중 다른 창을 조작하는 문제가 생긴다. 확인·알림·파일 선택만 대화상자로 띄운다.

### 2.3 UD-03 지난 일차 복습과 재시험의 진입점

- **배경**: 복습(FR-20)과 재시험(FR-19)은 대상이 같다(암기 완료 이상인 일차).
- **대안**: (a) 메인에 메뉴 두 개와 목록 화면 두 개, (b) "지난 일차" 목록 화면 하나에서 일차를 고른 뒤 복습·시험 중 선택.
- **결정 근거**: **(b) 채택.** 같은 목록을 두 번 만들지 않고 메인 메뉴가 줄어든다. 복습 카드 화면 안에는 시험 버튼을 두지 않으므로 FR-21 과 어긋나지 않는다.

### 2.4 UD-04 뜻 가리기 옵션

- **배경**: 기획서는 카드에 영단어와 뜻을 함께 보여 주도록 정했다(FR-10). 한편 유사 앱은 뜻을 가렸다가 확인하는 방식이 공통이고(현황·환경 분석서 I-04), v1.0 에서는 개선 후보로만 두었다.
- **대안**: (a) 넣지 않음, (b) 항상 가리고 뒤집기, (c) 기본은 함께 보기, 사용자가 켜면 가리기.
- **결정 근거**: **(c) 채택.** 기본 동작이 FR-10 그대로라 요구사항을 바꾸지 않는다. 스스로 떠올려 보는 연습을 원하는 사용자는 체크 한 번으로 쓸 수 있다. 구현은 화면 상태 하나라 로직·저장에 영향이 없다.
- **영향**: 가린 채 넘겨도 "본 카드"로 센다(암기 완료 판정은 FR-12 그대로). 설정은 저장하지 않으며 프로그램을 다시 켜면 꺼져 있다.

              N일차 학습    │       │지난 일차 │오답 학습 │단어 목록
                           ▼       ▼        ▼       ▼
                  S-02 카드      S-05      S-06     S-07
                  (일차 학습)   지난 일차   오답 목록  단어 목록 관리
                      │          │  │        │        │
             시험 보기 │   복습    │  │시험    │카드로    ├─ DL-05 → DL-02 (검증 실패)
          (암기 완료 후)│          ▼  │  보기   │ 학습    └─ DL-05 → DL-01 → 교체 → S-01
                      │   S-02 카드 │        ▼
                      │    (복습)   │   S-02 카드
                      │             │   (오답 학습)
                      ▼             ▼        │ 오답 시험 (모두 본 후)
                  S-03 시험 응시 (일차 시험)   ▼
                      │                  S-03 시험 응시 (오답 시험)
                 제출  │                      │ 제출
                      ▼                      ▼
                  S-04 시험 결과          S-04 시험 결과

- S-03 에서 '뒤로'·Esc·창 닫기를 누르면 DL-03 을 띄운다.
- S-01 로 돌아올 때마다 진도 현황을 다시 그린다(FR-09).

### 5.2 S-02 카드 (공용)

```
┌────────────────────────────────────────────────────────────┐
│  ← 뒤로          6일차 학습                        7 / 20    │
│                                                            │
│                                                            │
│                        issue                               │
│                                                            │
│        [명] 문제, 쟁점; (잡지의) 호 [동] 발행하다, 발급하다       │
│                                                            │
│                                                            │
│        [ ◀ 이전 ]                         [ 다음 ▶ ]        │
│                                                            │

```

| 요소 | 내용·동작 | FR |
|------|-----------|----|
| 제목 | 모드별 문구(아래 표) | — |
| 위치 | `현재 / 전체` | FR-10 |
| 영단어 | 가운데 정렬, 가장 큰 글자 | FR-10 |
| 뜻 | 뜻 칸 원문 그대로. 폭을 넘으면 줄바꿈 | FR-10, NFR-07 |
| 이전 / 다음 | 카드 이동. 끝에서는 비활성 | FR-11 |
| 안내 문구 | 하단 버튼이 꺼져 있는 이유 | FR-12 |
| 하단 버튼 | 모드별(아래 표) | FR-12, FR-24 |

| 모드 | 제목 | 하단 버튼 | 모두 본 뒤 | 추가 표시 |
|------|------|-----------|-----------|-----------|
| 일차 학습 | `N일차 학습` | `시험 보기` — 암기 완료 전 비활성 | 암기 완료를 기록·저장하고 버튼을 켠다. 안내 문구가 `암기 완료! 시험을 볼 수 있습니다` 로 바뀐다 | — |
| 복습 | `N일차 복습` | 없음 | 변화 없음 | — |
| 오답 학습 | `오답 학습` | `오답 시험` — 모두 보기 전 비활성 | 버튼을 켠다 | 뜻 아래에 `틀린 횟수 3 · 연속 정답 1 / 3` |

- 일차 학습 모드로 들어왔는데 그 일차가 이미 암기 완료면 `시험 보기` 가 처음부터 켜져 있다.
- 카드를 모두 보기 전에 '뒤로'를 누르면 확인 없이 나간다. 진행은 저장하지 않는다(D-03).

### 5.3 S-03 시험 응시 (공용)

```
┌────────────────────────────────────────────────────────────┐
│  ← 뒤로          6일차 시험                    문제 3 / 20    │
│  답한 문제 2 / 20                                            │
│                                                            │
│                      accommodate                           │
│                                                            │
│   ┌──────────────────────────────────────────────────┐     │
│   │ 1  [형] 관리의, 행정상의                             │     │
│   ├──────────────────────────────────────────────────┤     │
│   │ 2  [동] 수용하다, (요구 등을) 들어주다; 숙박 시설을      │     │
│   │    제공하다                                 ● 선택  │     │
│   ├──────────────────────────────────────────────────┤     │
│   │ 3  [명] 안건, 의제; 일정표                           │     │
│   ├──────────────────────────────────────────────────┤     │
│   │ 4  [동] 발표하다, 알리다                             │     │
│   └──────────────────────────────────────────────────┘     │
│                                                            │
│        [ ◀ 이전 ]        [ 다음 ▶ ]              [ 제출 ]    │
└────────────────────────────────────────────────────────────┘
```

| 요소 | 내용·동작 | FR |
|------|-----------|----|
| 제목 | `N일차 시험` 또는 `오답 시험` | — |
| 문제 위치 | `문제 현재 / 전체` | FR-15 |
| 답한 문제 수 | `답한 문제 n / 전체`. 제출 조건을 알려 준다 | FR-15 |
| 영단어 | 가운데 정렬 | FR-14 |
| 보기 4개 | 번호와 뜻 원문. 누르면 선택되고 선택 표시가 붙는다. 다시 다른 보기를 누르면 바뀐다. 긴 뜻은 줄바꿈하고 보기 높이가 늘어난다 | FR-14, NFR-07 |
| 이전 / 다음 | 문제 이동. 답하지 않고도 넘어갈 수 있고, 돌아가 답을 고칠 수 있다 | UD-01 |
| 제출 | 모든 문제에 답해야 켜진다. 누르면 채점·기록 반영·저장 후 S-04 로 이동 | FR-15, FR-26 |
| 뒤로 | DL-03 을 띄운다 | D-04 |

- 정답·오답은 이 화면에서 보여 주지 않는다(UD-01).
- 보기를 고르면 자동으로 다음 문제로 넘어가지 않는다. 고른 답을 확인할 틈을 주기 위함이다.
- 마지막 문제에서 답하지 않은 문제가 남아 있으면 제출 버튼 옆에 `답하지 않은 문제: 4, 11번` 을 보여 준다.

## 7. 공통 UI 규칙

### 7.1 창·배치

| 항목 | 규칙 |
|------|------|
| 창 크기 | 기본 960 × 700, 최소 800 × 600. 크기 조절 가능 |
| 창 제목 | `스마트 보카` |
| 여백 | 화면 가장자리 28px, 요소 사이 14px |
| 배치 | 절대 좌표를 쓰지 않고 레이아웃(`QVBoxLayout` 등)으로 배치해 창 크기에 따라 늘어나게 한다 |
| 시작 위치 | 화면 가운데 |

### 7.2 글자

| 용도 | 크기 | 굵기 |
|------|------|------|
| 카드·문제의 영단어 | 34pt(카드) / 32pt(문제) | 굵게 |
| 카드의 뜻 | 16pt | 보통 |
| 시험 보기 | 13pt | 보통 |
| 화면 제목 | 16pt | 굵게 |
| 버튼·본문·표 | 11pt | 보통 |
| 안내 문구 | 10pt | 보통, 흐린 색 |

영문·숫자는 Segoe UI, 한글은 맑은 고딕을 쓴다(글꼴 목록 `Segoe UI → Malgun Gothic`). 둘 다 Windows 기본 글꼴이라 따로 배포할 필요가 없다.

### 7.3 긴 뜻 처리 (NFR-07)

- 카드의 뜻과 결과 표의 셀은 자동 줄바꿈을 켠다.
- 시험 보기는 **줄바꿈되는 글자 영역을 가진 선택 항목**으로 만든다. `QPushButton` 과 `QRadioButton` 은 글자를 자동으로 줄바꿈하지 않으므로 그대로 쓰지 않는다. 구현 방법(줄바꿈 `QLabel` 을 담은 클릭 가능한 틀)은 구현 단계에서 PyQt 문서로 확인한 뒤 확정한다.
- 말줄임표(…)로 자르지 않는다. 이 문서의 와이어프레임에 있는 `…` 는 지면 사정으로 줄인 것이다.
- 검증: 기본 단어장에서 뜻이 가장 긴 단어(53자, obsolete)의 카드와, 그 뜻이 든 보기를 최소 창 크기(800 × 600)에서 띄워 전부 보이는지 확인한다.

### 7.4 버튼 상태

| 규칙 | 내용 |
|------|------|
| 비활성 이유 표시 | 조건이 있어 꺼진 버튼은 바로 옆에 이유를 적는다(시험 보기, 오답 시험, 제출) |
| 기본 버튼 | 화면마다 "다음에 할 일" 버튼 하나를 강조하고 Enter 에 연결한다 |
| 숨김과 비활성 | 그 화면·모드에서 의미가 없는 버튼은 숨기고(복습 모드의 시험 버튼), 조건을 채우면 쓸 수 있는 버튼은 비활성으로 보여 준다 |

### 7.5 키보드

| 키 | 동작 | 화면 |
|----|------|------|
| `→` / `←` | 다음 / 이전 | S-02, S-03 |
| `1` ~ `4` | 보기 선택 | S-03 |
| `Enter` | 기본 버튼 | 전체 |
| `Esc` | 뒤로 (S-03 에서는 DL-03) | S-02 ~ S-07 |

### 7.6 색·표시

| 용도 | 규칙 |
|------|------|
| 강조 | 기본 버튼과 진도 막대에 한 가지 강조색만 쓴다 |
| 정답·오답 | S-04 의 표에서 정답 뜻과 고른 뜻을 색만으로 구분하지 않고 열 제목으로 구분한다 |
| 선택한 보기 | 배경색과 `● 선택` 표시를 함께 쓴다(색만으로 구분하지 않는다) |
| 상태 | `완료` / `암기 완료` 는 글자로 적는다 |

색 값과 스타일시트는 `src/smartvoca/ui/theme.py` 한곳에 둔다. 강조색은 남보라(`#4f5bd5`) 하나이고 배경은 옅은 회색(`#f3f5fa`), 패널은 흰색이다. Windows 가 어두운 테마여도 밝은 배색으로 고정한다.

### 7.7 문구

- 존댓말, 짧은 문장. 버튼은 동작을 적는다(`확인` 대신 `바꾸기`, `그만두기`).
- 번호는 사용자에게 1 부터 보여 준다(단어 순번, 줄 번호, 문제 번호).
- 오류 문구에는 무엇이 문제이고 어떻게 고치는지를 함께 적는다.

## 10. v1.1 구현 반영 사항

§5 의 와이어프레임은 배치의 뼈대이고, 실제 화면은 아래처럼 다듬었다. 요소의 동작과 조건은 §5 의 표 그대로다.

| 화면 | 바뀐 점 | 이유 |
|------|---------|------|
| 공통 | 색·글꼴·둥근 모서리·그림자를 `theme.py` 로 통일. '뒤로'는 테두리 없는 버튼, 화면마다 강조 버튼은 하나이고 오른쪽 아래에 둔다 | 다음에 할 일이 어디 있는지 화면마다 같게 |
| 공통 | 머리줄 오른쪽 정보(`7 / 20`, `문제 3 / 20`)를 알약 모양 표시로 | 위치 정보를 제목과 구분 |
| S-01 | 오늘의 학습을 강조색 배경의 큰 패널로, 진도 막대를 그 안에 배치 | 들어오자마자 할 일이 가장 크게 보이게 |
| S-01 | 현황 칸 3개 추가: 완료한 일차 / 시험까지 마친 단어 / 오답 단어 | 쌓인 양을 숫자로 보여 줘 동기 부여 (FR-09 범위 안) |
| S-01 | 메뉴 3개를 표식·제목·설명이 든 큰 버튼으로. 하단에 `Enter` 안내 | 메뉴가 무엇을 하는지 누르기 전에 알 수 있게 |
| S-02 | 머리줄 아래에 위치 막대 추가 | 몇 장 남았는지 한눈에 |
| S-02 | `뜻 가리고 외우기` 체크와 `뜻 보기 (Space)` 버튼 추가 | UD-04 |
| S-03 | 문제 번호 점 추가: 답한 문제는 색을 채우고 현재 문제는 굵은 테두리. 누르면 그 문제로 이동. 문제가 60개를 넘으면 점 대신 막대 | 답하지 않은 문제를 찾아가기 쉽게 (FR-15) |
| S-03 | 보기 번호를 동그란 표시로, 선택 표시는 `✓ 선택` | 색과 글자 두 가지로 선택을 구분 |
| S-04 | 점수를 고리 그림(맞은 수 / 전체, 정답률)과 한 줄 격려 문구로 | 결과를 한눈에. 고리 색은 정답률 90% 이상 초록, 60% 이상 남보라, 그 밖 주황이며 숫자를 항상 함께 적는다 |
| S-05 ~ S-06 | 표에 줄무늬·행 강조, 단어 열 굵게 | 긴 목록에서 줄을 따라가기 쉽게 |
| S-07 | 동작마다 제목·설명·버튼을 한 줄 패널로 | 버튼이 무엇을 하는지 옆에서 바로 설명 |
| 창 | 앱 아이콘을 코드로 그려서 지정 | 그림 파일 배포 불필요 |

추가된 공용 부품(`ui/widgets.py`): `MenuCard`, `StatTile`, `QuestionDots`, `ScoreRing`. 단축키에 `Space`(뜻 보기)를 더했다.
