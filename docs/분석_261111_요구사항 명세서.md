## 2. 기획서 대비 추가 확정 사항

기획서에서 설계 단계로 넘기거나 명시하지 않은 동작을 요구사항 수준에서 확정한다. 2026-11-11 사용자가 승인했다.

### 2.1 D-01 다른 단어장을 불러올 때 기존 학습 기록 처리 (기획서 §6.7 미결)

- **배경**: 학습 기록(일차 완료 여부, 오답 횟수)은 단어장의 단어 순서·구성에 묶여 있다. 단어장이 바뀌면 "3일차 완료" 같은 기록이 가리키는 단어가 달라진다.
- **대안**
  - (a) 확인 후 기록 초기화: 새 단어장은 1일차부터 다시 시작한다.
  - (b) 단어장별 기록 분리 보관: 단어장마다 기록을 따로 두고 전환할 때 복원한다.
  - (c) 단어 일치 기준 승계: 같은 영단어의 오답 기록만 새 단어장으로 옮긴다.
- **결정 근거**: **(a) 채택.** 구현과 테스트가 가장 단순하고, 기록과 단어장이 어긋날 여지가 없다. (b) 는 단어장 식별·목록 관리 기능이 추가로 필요해 범위가 커지고, (c) 는 일차 진도는 어차피 옮길 수 없어 기록이 반쪽만 남는다. 기록 손실 위험은 교체 전 확인 대화상자와 오답 목록 내보내기 안내로 줄인다. → FR-04

### 2.2 그 밖의 명시 사항

| ID | 내용 | 근거 | 반영 |
|----|------|------|------|
| D-02 | 단어장은 **단어 4개 이상, 서로 다른 뜻 4개 이상**이어야 한다 | 4지선다 보기를 만들 수 없는 단어장을 막기 위함 | FR-02 |
| D-03 | 암기 도중 나가면 "본 카드" 진행은 저장하지 않는다. 다시 들어오면 첫 카드부터 본다 | 기획서 §7 의 저장 대상이 일차별 완료 여부까지이므로 그 범위를 유지 | FR-12 |
| D-04 | 시험 도중 나가면 그 시험은 없던 것으로 한다 (점수·오답 미반영) | 일부만 푼 결과로 일차가 완료 처리되는 것을 막기 위함 | FR-15 |
| D-05 | 일차 시험에서 **맞힌** 단어는 연속 정답 횟수를 바꾸지 않는다. **틀린** 단어는 0 으로 되돌린다 | 기획서 §6.6: 연속 정답은 오답 시험 기준, 일차 시험에서 틀리면 다시 등재 | FR-17 |
| D-06 | 오답 목록에서 빠져도 오답 횟수(누적)는 지우지 않는다 | 다시 틀려 재등재될 때 정렬 순서에 누적 횟수를 쓰기 위함 | FR-25 |
| D-07 | "이미 학습한 일차"(복습 대상)는 **암기 완료 이상**인 일차로 본다. (2026-11-25 잠금 폐지로 모든 일차를 고를 수 있게 되어, 이 구분은 일차 목록의 상태 표시로만 남는다 — ADR-21, ADR-22) | 기획서 §6.5 의 표현을 판정 가능한 조건으로 구체화 | FR-20 |
| D-08 | 오답 목록 정렬에서 오답 횟수가 같으면 단어장 순서를 따른다 | 정렬 결과를 항상 같게 하여 테스트 가능하게 함 | FR-22 |
| D-09 | **CSV 가져오기 중복 처리** (VOCA-FR-003): 영단어는 대소문자를 무시하고 같으면 같은 단어다. ① *추가* 모드는 이미 있는 단어를 건너뛰고 기존 뜻·이력을 그대로 둔다. ② 파일 안에서 겹치면 앞줄만 쓰고 겹친 줄 번호를 알려 준다. ③ *바꾸기* 모드는 기존 단어와 모든 이력을 지우고 파일 내용으로 새로 시작한다(확인 필요). 직접 등록·수정에서 이미 있는 영단어는 거절한다 | 기존 학습 이력을 지키고, 결과를 예측할 수 있게 함 (ADR-28) | FR-02, FR-03, FR-04, FR-31, FR-32 |
| D-10 | 일차 상태는 저장하지 않고 **단어 이력에서 계산**한다. 암기 완료 = 그 일차 모든 단어에 암기 이력, 완료 = 모든 단어가 일차 시험에 나옴. 하루 학습량을 바꿔 일차가 다시 나뉘어도 외운 단어는 외운 채로 남는다 | 일차 편성이 설정으로 바뀌므로 일차 번호에 기록을 묶을 수 없음 (ADR-26) | FR-08, FR-12, FR-18 |

| FR-02 | **CSV 형식 검증** — 가져오는 CSV 의 헤더(`word,meaning` 또는 과제 제공 형식 `영단어,뜻`), 빈 칸, 인코딩(UTF-8 BOM 유무, CP949)을 검사한다. 파일 안 영단어 중복(대소문자 무시)은 앞줄만 쓰고 줄 번호를 알린다(D-09). (v1.5 최소 크기 규칙은 4지선다를 만들 때 검사하도록 옮김, FR-14) | 헤더가 틀리거나 빈 칸이 있는 파일은 가져오지 않고, 어긴 조건과 행 번호를 알려 준다. 기존 단어장과 학습 기록은 그대로다. 과제 제공 CSV 와 기본 단어장 모두 읽힌다. |
| FR-03 | **CSV 가져오기 (일괄 등록)** — 브라우저에서 고른 CSV 를 검증(FR-02)하고 확인 화면에서 *추가* 또는 *바꾸기*를 고르게 한다. *추가*는 없는 단어만 단어장 끝에 더한다(D-09). (v1.5 '교체만'에서 추가·바꾸기로, ADR-28) | 2,000개 제공 CSV 를 기본 단어장에 *추가*하면 새 단어만 늘고 건너뛴 단어 수가 안내된다. 가져온 단어는 재실행 후에도 남는다. 원본 CSV 와 `data/toeic_words.csv` 는 수정되지 않는다. |
| FR-04 | **바꾸기 시 기록 초기화** — *바꾸기*를 고르면 학습 기록이 지워진다는 확인을 받고, 승인하면 단어와 암기·시험 이력·오답 목록을 모두 지운 뒤 파일 내용으로 새로 시작한다. | 확인 화면에서 취소하면 단어장과 기록이 그대로다. 승인하면 모든 일차가 `학습 전` 이고 오답 목록이 빈다. 진행 중이던 카드·시험 화면도 사라진다. 확인 화면에 오답 목록 내보내기(FR-06) 안내가 있다. |
| FR-05 | **단어장 내보내기** — 현재 단어장(DB 의 단어)을 CSV(`word,meaning`, `utf-8-sig`)로 저장한다. 웹에서는 브라우저 다운로드로 받으며 저장 위치는 브라우저 설정을 따른다. | 내보낸 파일을 다시 불러오면(FR-03) 단어 수·순서·뜻이 원래와 같다. |
| FR-06 | **오답 목록 내보내기** — 현재 오답 목록을 CSV 로 저장한다(웹: 브라우저 다운로드). 열은 영단어, 뜻, 오답 횟수이며 순서는 FR-22 와 같다. | 오답 목록의 단어 수와 내보낸 행 수가 같다. 오답 목록이 비어 있으면 내보내지 않고 안내한다. |
| FR-29 | **단어장 조회·검색** (VOCA-FR-002, 004) — 현재 단어장의 단어를 일차·영단어·뜻으로 보여 주고, 검색어가 영단어나 뜻에 들어 있는 단어만 걸러 본다(대소문자 무시). `12` 나 `12일차` 를 넣으면 그 일차의 단어를 보여 준다. 검색이 없으면 처음 500개만 그리고 나머지는 검색으로 찾게 한다. 각 행에서 수정·삭제(FR-32)로 간다. (2026-11-18 추가, 번호는 추가 순. v1.5 500개 제한·수정 연결) | 검색 없이 열면 앞 500행과 전체 단어 수가 나온다. `executive` 로 찾으면 1개, `12` 를 넣으면 12일차 단어가 나온다. 500번째 뒤의 단어도 검색으로 찾힌다. 결과가 없으면 안내 문구가 나온다. |
| FR-31 | **단어 직접 등록** (VOCA-FR-001) — 영단어와 뜻을 입력해 단어장 끝에 더한다. 앞뒤 공백을 지우고, 빈 칸·너무 긴 값·이미 있는 영단어(대소문자 무시)는 거절한다. (v1.5 추가) | `sustain` 을 등록하면 목록 끝에 나오고 재실행 후에도 남는다. `Sustain` 을 또 등록하면 거절되고 이유가 보인다. 단어를 더하면 마지막 일차가 그 단어를 포함해 다시 `학습 전` 이 될 수 있다(D-10). |
| FR-32 | **단어 수정·삭제** (VOCA-FR-002) — 목록에서 고른 단어의 영단어·뜻을 고치거나 지운다. 지울 때는 확인을 받는다. 지운 단어의 오답 기록은 지우고, 암기·시험 이력은 통계를 위해 글자로 남긴다. (v1.5 추가) | 뜻을 고치면 카드·시험에 바뀐 뜻이 나온다. 다른 단어와 같은 영단어로 고치면 거절된다. 지운 단어는 목록·오답 목록에서 사라지지만 통계의 시험 정답률은 그대로다. |

### 3.2 진도 생성 (SC-03)

| ID | 요구사항 | 수용 기준 |

| FR-07 | **일차 편성** (VOCA-FR-011) — 단어장을 순서대로 하루 학습량(기본 20, 5~100, FR-36)씩 나눠 1일차부터 차례로 배정한다. 나누어떨어지지 않으면 마지막 일차는 남은 단어로 구성한다. | 2,000 단어·20개 → 100일차, 1일차는 1~20번·100일차는 1,981~2,000번 단어. 2,010 단어 → 101일차(마지막 10개). 하루 학습량을 30 으로 바꾸면 2,109 단어가 71일차가 된다. 모든 단어가 정확히 한 일차에만 속한다. |

(2026-11-25 잠금 폐지, ADR-21) | 초기 상태에서 모든 일차가 `학습 전` 이고 오늘의 학습은 1일차다. 1일차를 끝내지 않아도 30일차를 학습·시험할 수 있고, 그 뒤에도 오늘의 학습은 1일차다. 같은 날 여러 일차를 진행할 수 있다. 모든 일차를 완료하면 추천할 일차가 없음을 알린다. |
| FR-09 | **진도 현황 표시** (VOCA-FR-031) — 메인 화면에 현재 일차, 외운 단어 수 / 전체 단어 수, 완료한 일차 수 / 전체 일차 수, 오답 목록의 단어 수를 보여 준다. | 표시 값이 DB 이력과 일치한다. 시험 제출 직후 메인 화면으로 돌아오면 값이 갱신되어 있다. |

### 3.4 일차 시험 (SC-05)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-13 | **응시 조건** — 암기 완료 이상인 일차만 시험을 볼 수 있다. | `학습 전`(암기 미완료) 일차에서는 시험을 시작할 수 없다. |
| FR-14 | **문제 생성** (VOCA-FR-023, 024) — 대상 단어마다 문제 1개를 만든다. 형식은 **4지선다·단답형·OX** 중 하나, 방향은 **영→한·한→영·섞기**(문제마다 무작위) 중 하나를 시험 설정에서 고른다(기본값은 FR-36). 4지선다의 오답 보기 3개는 단어장 전체에서 다른 단어의 뜻(한→영이면 영단어)을 뽑으며 4개가 서로 다르다. OX 는 절반쯤 맞는 짝, 나머지는 다른 단어의 짝을 보여 준다. 문제 순서와 보기 위치는 무작위다. (v1.5 형식·방향 추가, ADR-27) | 20 단어 일차 → 20문제, 단어가 한 번씩만 출제된다. 4지선다는 정답 보기가 정확히 1개이고 보기가 서로 다르다. 한→영 보기에 뜻이 같은 다른 단어가 나오지 않는다. 서로 다른 뜻이 4개 미만이면 4지선다를 만들지 않고 알린다(단답형은 만들 수 있다). 같은 난수 시드면 같은 시험지가 만들어진다(NFR-04). |
| FR-15 | **응시 진행** — 문제를 한 개씩 보여 주고 보기를 고르게(단답형은 입력하게) 한다. 모든 문제에 답해야 제출할 수 있다. 도중에 나가면 그 시험은 반영하지 않는다. | 답하지 않은 문제가 있으면 제출할 수 없다. 도중에 나가면 일차 상태·오답 횟수·오답 목록이 바뀌지 않는다. |
| FR-16 | **채점 결과 표시** (VOCA-FR-025) — 제출하면 맞은 수 / 전체 문제 수와 틀린 문항(문제, 정답, 내 답)을 보여 준다. 단답형은 영→한이면 뜻 조각 하나만 맞혀도(띄어쓰기·괄호 무시), 한→영이면 철자가 같으면(대소문자·앞뒤 공백 무시) 정답이다. (v1.5 단답형 채점 추가, ADR-27) | 20문제 중 3개를 틀리면 `17 / 20` 과 틀린 문항 3개가 정답과 함께 표시된다. 뜻 `[명] 문제, 쟁점` 에 `쟁점` 이라고 쓰면 정답이다. |
| FR-17 | **오답 기록** — 틀린 단어마다 오답 횟수를 1 늘리고 연속 정답 횟수를 0 으로 되돌린 뒤 오답 목록에 올린다. 맞힌 단어의 기록은 바꾸지 않는다. | 처음 틀린 단어: 오답 횟수 1, 오답 목록에 등재. 이미 목록에 있던 단어를 또 틀리면 오답 횟수만 늘고 중복 등재되지 않는다. |
| FR-18 | **일차 완료 처리** — 시험을 제출하면 점수와 관계없이 그 일차를 완료로 기록하고, 다음에 할 일차(FR-08 오늘의 학습)를 안내한다. | 0점으로 제출해도 일차가 완료된다. 1일차를 완료하면 `다음 추천은 2일차` 를, 1일차를 남긴 채 30일차를 완료하면 `다음 추천은 1일차` 를 안내한다. |
| FR-19 | **재시험** — 완료한 일차의 시험을 다시 볼 수 있다. 오답 기록(FR-17)은 같은 방식으로 반영하고, 일차 상태는 완료를 유지한다. 시험마다 회차·문항 이력이 새로 남는다(FR-26). | 완료한 1일차를 재시험해 2개를 틀리면 두 단어의 오답 횟수가 1씩 늘어난다. 문제 순서는 시험마다 새로 섞인다. |

| FR-25 | **오답 시험 결과 반영** — 맞힌 단어는 연속 정답 횟수를 1 늘리고, 3 이 되면 오답 목록에서 뺀다. 틀린 단어는 연속 정답 횟수를 0 으로 되돌리고 오답 횟수를 1 늘린다. 목록에서 빠져도 누적 오답 횟수는 유지한다. | 같은 단어를 오답 시험에서 3번 연속 맞히면 목록에서 사라진다. 2번 맞히고 1번 틀리면 연속 정답 횟수가 0 이 되고 목록에 남는다. 빠진 단어를 일차 시험에서 다시 틀리면 연속 정답 횟수 0 으로 다시 등재된다. |

### 3.9 기말 과제 추가 기능 (v1.5)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FR-33 | **복습 카드 섞기** (VOCA-FR-013) — 일차 학습 카드 뒤에 복습 카드를 복습 수(기본 4, 0~20, FR-36)만큼 붙인다. 절반은 **전날 일차에서 암기 이력이 있는 단어**, 나머지는 **오답 목록에서 자주 틀린 단어**에서 무작위로 고르고, 한쪽이 모자라면 다른 쪽으로 채운다. 그날 단어와 겹치지 않는다. 복습 카드도 암기 이력에 카드 종류와 함께 남는다. (ADR-27) | 1일차를 외운 뒤 2일차 카드를 열면 20장 + 복습 카드가 나오고 복습 카드에 종류 표시가 있다. 1일차이거나 전날 외운 이력이 없으면 전날 카드가 없다. 복습 수 0 이면 그날 단어만 나온다. |
| FR-34 | **실력 시험 (문제 수·가중 출제)** (VOCA-FR-021, 022) — 시험 설정 화면에서 문제 수(1~100)·방향·형식을 정해 외운 단어(없으면 전체)에서 출제한다. 단어마다 가중치 `1 + 3·(시험 본 적 없음) + min(지난 날 수, 30)/10 + 2·min(누적 오답, 5)` 를 주고 겹치지 않게 가중 무작위로 고른다(Efraimidis–Spirakis). 실력 시험 결과도 오답 기록(FR-17)과 문항 이력(FR-26)에 반영한다. (ADR-27) | 문제 수 7 → 7문제, 단어가 겹치지 않는다. 여러 번 뽑으면 가중치가 큰 단어가 작은 단어보다 많이 나온다. 같은 시드면 같은 시험지다. |
| FR-35 | **학습 진척 통계** (VOCA-FR-031 ~ 034) — 통계 화면에 현재 일차, 외운 단어 수 / 전체, 완료한 일차, 전체 정답률·시험 횟수, 회차별 정답률(최근 회차 막대), 날짜별 정답률(막대 + 표), 자주 틀리는 단어 상위 N개(틀린 횟수·출제 횟수)를 보여 준다. 모든 값은 요청 때마다 DB 의 암기·시험 이력에서 계산하며 화면에 값을 써 넣지 않는다. | 시험을 2회 보면 회차 막대가 2개이고 각 정답률이 `exam_item` 집계와 같다. 시험 이력이 없으면 안내 문구가 나온다. 단어를 지워도 이미 본 시험의 정답률은 바뀌지 않는다. |
| FR-36 | **설정** (VOCA-FR-061, 062) — 설정 화면에서 하루 학습량(5~100), 복습 수(0~20), 시험 기본 문제 수(1~100)·방향·형식을 바꾼다. 범위를 벗어나면 거절하고 이유를 보여 준다. 설정은 사용자별 `setting` 행에 저장되어 다시 접속해도 유지된다. | 하루 학습량을 바꿔 저장하면 일차 목록이 다시 나뉘고 외운 단어는 외운 채로 남는다(D-10). 시험 설정 화면의 기본값이 저장한 값으로 바뀐다. 재실행 후에도 같은 값이다. |
