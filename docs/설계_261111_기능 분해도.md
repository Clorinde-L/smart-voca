## 3. 단위 기능 명세

### 3.1 F-01 단어 데이터 관리 (SC-01)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-01-01 | CSV 읽기 | 로직 | CSV 를 `utf-8-sig` 로 읽어(안 되면 `cp949`) (영단어, 뜻) 목록을 순서대로 돌려준다. 헤더는 `word,meaning`·`영단어,뜻` 둘 다 받는다. v1.4: 올린 파일은 디스크에 쓰지 않고 바이트로 받는다 | FR-01, FR-03, NFR-08, VOCA-FR-003 |
| F-01-02 | 단어장 검증 | 로직 | 헤더, 열 개수, 빈 칸, 길이(영단어 100자·뜻 300자)를 검사하고 위반 항목과 행 번호를 돌려준다. v1.4: 파일 안의 중복 영단어는 위반이 아니라 "앞줄만 씀"으로 줄 번호를 따로 돌려준다(ADR-28) | FR-02, VOCA-FR-003 |
| F-01-03 | 기본 단어장 로드 | 로직 | v1.4: 빈 DB 를 처음 준비할 때 한 번만 `data/toeic_words.csv` 를 읽어 `word` 테이블에 넣는다(`PRAGMA user_version` 으로 판단, ADR-25) | FR-01 |
| F-01-04 | 단어장 교체 | 로직 | CSV 가져오기의 "바꾸기". 단어와 모든 학습 기록을 지우고(F-07-03, 설정은 유지) 검증을 통과한 단어를 넣는다. 한 트랜잭션 | FR-03, FR-04, VOCA-FR-003 |
| F-01-05 | 단어장 CSV 쓰기 | 로직 | 현재 단어장을 `영단어,뜻` 헤더의 `utf-8-sig` CSV 바이트로 만든다(브라우저 다운로드) | FR-05, NFR-08 |
| F-01-06 | 오답 목록 CSV 쓰기 | 로직 | 정렬된 오답 목록(F-06-01)을 영단어·뜻·오답 횟수 열의 CSV 바이트로 만든다 | FR-06, NFR-08 |
| F-01-07 | 단어장 불러오기 화면 처리 | UI | 파일 고르기, 검증 오류 표시(DL-02), 추가 / 바꾸기 확인 화면(DL-01, 새 단어·이미 있는 단어·겹친 줄 수, 바꾸기는 한 번 더 확인) | FR-02, FR-03, FR-04, VOCA-FR-003 |
| F-01-08 | 내보내기 화면 처리 | UI | 단어장·오답 목록 각각의 저장 경로 선택, 완료·빈 목록 안내 | FR-05, FR-06 |
| F-01-09 | 단어 목록 조회·검색 | UI | 현재 단어장을 일차·영단어·뜻 표로 보여 주고, 영단어·뜻 검색어나 일차 번호로 거른다. 결과 수와 빈 결과를 안내한다. 검색어가 없으면 처음 500행만 그린다 | FR-29, VOCA-FR-004 |
| F-01-10 | 단어 등록 | 로직 | 영단어·뜻을 검사(빈 칸, 길이, 이미 있는 영단어 — 대소문자 무시)하고 단어장 맨 뒤에 넣는다 | VOCA-FR-001 |
| F-01-11 | 단어 수정 | 로직 | 같은 검사(자기 자신은 빼고 중복 검사) 뒤 영단어·뜻을 고친다. 기록은 `word.id` 에 붙어 있어 이어진다 | VOCA-FR-002 |
| F-01-12 | 단어 삭제 | 로직 | 단어와 그 단어의 오답 기록을 지운다. 암기·시험 이력은 영단어 글자와 함께 남고 `word_id` 만 비운다(통계 유지) | VOCA-FR-002 |
| F-01-13 | 단어 관리 화면 | UI | 등록 칸, 행마다 수정(S-07a)·삭제(DL-06 확인). 입력 오류는 이유와 함께 적은 값을 돌려준다 | VOCA-FR-001, 002 |
| F-01-14 | CSV 추가 가져오기 | 로직 | CSV 가져오기의 "추가". 이미 있는 영단어(대소문자 무시)는 건너뛰고 기존 뜻을 유지, 새 단어만 맨 뒤에 넣는다. 넣은 수·건너뛴 수를 돌려준다(ADR-28) | VOCA-FR-003 |

### 3.2 F-02 진도 관리 (SC-03)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-02-01 | 일차 편성 | 로직 | 단어장을 순서대로 하루 학습량(설정, 기본 20)씩 나눠 일차 번호와 단어 범위를 만든다. 마지막 일차는 나머지로 구성한다 | FR-07, VOCA-FR-011 |
| F-02-02 | 일차 상태 판정 | 로직 | 일차별 상태(학습 전 / 암기 완료 / 완료)와 현재 일차(완료하지 않은 가장 앞 일차)를 계산한다. 잠금은 없다(ADR-21). v1.4: 그 일차의 모든 단어에 암기 이력이 있으면 암기 완료, 모든 단어가 일차 시험에 나왔으면 완료(ADR-26) | FR-08 |
| F-02-03 | 진도 현황 집계 | 로직 | 현재 일차, 전체 일차 수, 완료 일차 수, 암기 완료 일차 수, 외운 단어 수 / 전체 단어 수, 오답 목록 단어 수를 돌려준다 | FR-09, VOCA-FR-031 |
| F-02-04 | 메인 화면 표시 | UI | 진도 현황, 오늘의 학습, 전체 일차의 상태 칸('일차 한눈에'), 실력 시험 버튼을 보여 준다. 각 화면으로는 공통 메뉴 막대로 이동한다. 다른 화면에서 돌아오면 현황을 갱신한다 | FR-08, FR-09 |

### 3.3 F-03 일차 학습 – 암기 (SC-04)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-03-01 | 카드 묶음 진행 관리 | 로직 | 단어 목록을 받아 현재 위치, 다음·이전 이동 가능 여부, 본 카드 집합, "모두 봄" 여부를 관리한다. **일차 학습(복습 포함)·오답 학습이 공용으로 쓴다** | FR-10, FR-11, FR-12, FR-21, FR-23, FR-24 |
| F-03-02 | 암기 완료 기록 | 로직 | 일차의 카드를 모두 보면 본 카드마다 암기 이력(단어, 종류 그 일차 / 복습 / 오답, 시각)을 저장(F-07-01)한다. 이미 끝낸 일차여도 남긴다. 일차 상태는 이 이력으로 계산된다(F-02-02) | FR-12, FR-26, VOCA-FR-014 |
| F-03-03 | 카드 화면 표시·이동 | UI | 카드 1장(영단어, 뜻 원문, `n / 전체`)과 '다음'·'이전' 버튼. 긴 뜻은 줄바꿈한다. **공용 화면 부품** | FR-10, FR-11, NFR-07 |
| F-03-04 | 일차 학습 화면 처리 | UI | 고른 일차(오늘의 학습 또는 일차 상세에서 고른 일차)의 카드 화면을 열고, 암기 완료 시 시험 버튼을 활성화한다. 이미 암기 완료 이상인 일차면 기록을 바꾸지 않고(복습) 시험 버튼을 처음부터 켠다 | FR-12, FR-13, FR-21 |
| F-03-05 | 발음 듣기 | UI | 영단어를 브라우저 내장 음성으로 읽는다. 카드·시험·일차 상세·오답 목록에서 쓴다. 음성을 쓸 수 없으면 버튼을 숨긴다 | FR-30 |
| F-03-06 | 복습 카드 섞기 | 로직 | 일차 카드 뒤에 복습 카드 수(설정, 기본 4)만큼 붙인다. 절반은 전날 일차의 외운 단어, 나머지는 오답 목록 앞쪽. 한쪽이 모자라면 다른 쪽에서 채우고 그날 단어와 겹치면 뺀다. 난수 시드를 주입받는다 | VOCA-FR-013, NFR-04 |

### 3.4 F-04 시험 – 일차·실력 (SC-05)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-04-01 | 응시 가능 판정 | 로직 | 일차 상태가 암기 완료 이상인지 확인한다 | FR-13, FR-19 |
| F-04-02 | 시험지 생성 | 로직 | 대상 단어마다 고른 형식·방향(F-04-09)으로 문제를 만든다. 4지선다의 오답 보기 3개는 단어장 전체에서 정답과 뜻이 다른 것으로 무작위 선택하고, 문제 순서와 보기 위치를 섞는다. 난수 시드를 주입받는다. **일차·오답·실력 시험이 공용으로 쓴다** | FR-14, FR-24, NFR-04 |
| F-04-03 | 채점 | 로직 | 시험지와 답안을 받아 문항별 정오(문제, 정답, 내 답, 형식, 방향)와 맞은 수, 전체 수를 돌려준다. 단답형은 대소문자·띄어쓰기·괄호를 무시하고, 영→한은 뜻 조각 하나만 맞아도 정답(ADR-27). 답하지 않은 문제가 있으면 채점하지 않는다. **공용** | FR-15, FR-16, VOCA-FR-025 |
