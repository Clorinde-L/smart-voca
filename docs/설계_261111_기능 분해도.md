## 2. 기능 계층도

```
스마트 보카 (smart-voca)
├─ F-01 단어 데이터 관리

│   ├─ F-01-02 단어장 검증                  [로직]
│   ├─ F-01-03 기본 단어장 로드              [로직]
│   ├─ F-01-04 단어장 교체                  [로직]
│   ├─ F-01-05 단어장 CSV 쓰기              [로직]
│   ├─ F-01-06 오답 목록 CSV 쓰기            [로직]
│   ├─ F-01-07 단어장 불러오기 화면 처리       [UI]
│   └─ F-01-08 내보내기 화면 처리            [UI]
├─ F-02 진도 관리
│   ├─ F-02-01 일차 편성                    [로직]
│   ├─ F-02-02 일차 상태 판정                [로직]
│   ├─ F-02-03 진도 현황 집계                [로직]
│   └─ F-02-04 메인 화면 표시                [UI]
├─ F-03 일차 학습 (암기)
│   ├─ F-03-01 카드 묶음 진행 관리            [로직]
│   ├─ F-03-02 암기 완료 기록                [로직]
│   ├─ F-03-03 카드 화면 표시·이동            [UI]
│   └─ F-03-04 일차 학습 화면 처리            [UI]
├─ F-04 일차 시험
│   ├─ F-04-01 응시 가능 판정                [로직]

│   ├─ F-05-01 복습 대상 일차 조회            [로직]

│   ├─ F-06-01 오답 목록 조회·정렬            [로직]
│   ├─ F-06-02 오답 시험 결과 반영            [로직]
│   ├─ F-06-03 오답 학습 화면 처리            [UI]
│   └─ F-06-04 오답 시험 화면 처리            [UI]
```

## 3. 단위 기능 명세

### 3.1 F-01 단어 데이터 관리 (SC-01)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-01-01 | CSV 읽기 | 로직 | 경로의 CSV 를 `utf-8-sig` 로 읽어 (영단어, 뜻) 목록을 순서대로 돌려준다 | FR-01, FR-03, NFR-08 |
| F-01-02 | 단어장 검증 | 로직 | 헤더, 빈 칸, 영단어 중복(대소문자 무시), 최소 크기(단어 4개·서로 다른 뜻 4개)를 검사하고 위반 항목과 행 번호를 돌려준다 | FR-02 |
| F-01-03 | 기본 단어장 로드 | 로직 | 불러온 단어장이 없으면 `data/toeic_words.csv` 를 읽어(F-01-01) 검증(F-01-02)한 뒤 단어장으로 쓴다 | FR-01 |
| F-01-04 | 단어장 교체 | 로직 | 검증을 통과한 단어 목록을 현재 단어장으로 바꾸고 보관한다. 기록 초기화(F-07-03)와 일차 재편성(F-02-01)을 함께 수행한다 | FR-03, FR-04 |
| F-01-05 | 단어장 CSV 쓰기 | 로직 | 현재 단어장을 `word,meaning` 형식 `utf-8-sig` CSV 로 지정 경로에 쓴다 | FR-05, NFR-08 |
| F-01-06 | 오답 목록 CSV 쓰기 | 로직 | 정렬된 오답 목록(F-06-01)을 영단어·뜻·오답 횟수 열의 CSV 로 지정 경로에 쓴다 | FR-06, NFR-08 |
| F-01-07 | 단어장 불러오기 화면 처리 | UI | 파일 선택 대화상자, 검증 오류 표시, 기록 초기화 확인 대화상자(오답 목록 내보내기 안내 포함) | FR-02, FR-03, FR-04 |
| F-01-08 | 내보내기 화면 처리 | UI | 단어장·오답 목록 각각의 저장 경로 선택, 완료·빈 목록 안내 | FR-05, FR-06 |

### 3.2 F-02 진도 관리 (SC-03)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-02-01 | 일차 편성 | 로직 | 단어장을 순서대로 20개씩 나눠 일차 번호와 단어 범위를 만든다. 마지막 일차는 나머지로 구성한다 | FR-07 |
| F-02-02 | 일차 상태 판정 | 로직 | 학습 기록에서 일차별 상태(잠김 / 학습 가능 / 암기 완료 / 완료)와 현재 일차를 계산한다. 1일차는 항상 열려 있고 직전 일차가 완료면 연다 | FR-08 |
| F-02-03 | 진도 현황 집계 | 로직 | 현재 일차, 전체 일차 수, 완료 일차 수, 오답 목록 단어 수를 돌려준다 | FR-09 |
| F-02-04 | 메인 화면 표시 | UI | 진도 현황과 일차 학습·복습·오답·단어 목록 메뉴를 보여 주고 각 화면으로 이동한다. 다른 화면에서 돌아오면 현황을 갱신한다 | FR-08, FR-09 |

### 3.3 F-03 일차 학습 – 암기 (SC-04)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-03-01 | 카드 묶음 진행 관리 | 로직 | 단어 목록을 받아 현재 위치, 다음·이전 이동 가능 여부, 본 카드 집합, "모두 봄" 여부를 관리한다. **일차 학습·복습·오답 학습이 공용으로 쓴다** | FR-10, FR-11, FR-12, FR-21, FR-23, FR-24 |
| F-03-02 | 암기 완료 기록 | 로직 | 일차의 카드를 모두 보면 그 일차를 암기 완료로 기록하고 저장(F-07-01)한다 | FR-12, FR-26 |
| F-03-03 | 카드 화면 표시·이동 | UI | 카드 1장(영단어, 뜻 원문, `n / 전체`)과 '다음'·'이전' 버튼. 긴 뜻은 줄바꿈한다. **공용 화면 부품** | FR-10, FR-11, NFR-07 |
| F-03-04 | 일차 학습 화면 처리 | UI | 현재 일차의 카드 화면을 열고, 암기 완료 시 시험 버튼을 활성화한다 | FR-12, FR-13 |

### 3.4 F-04 일차 시험 (SC-05)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-04-01 | 응시 가능 판정 | 로직 | 일차 상태가 암기 완료 이상인지 확인한다 | FR-13, FR-19 |
| F-04-02 | 시험지 생성 | 로직 | 대상 단어마다 4지선다 문제를 만든다. 오답 보기 3개는 단어장 전체에서 정답과 뜻이 다른 것으로 무작위 선택하고, 문제 순서와 보기 위치를 섞는다. 난수 시드를 주입받는다. **일차 시험·오답 시험이 공용으로 쓴다** | FR-14, FR-24, NFR-04 |
| F-04-03 | 채점 | 로직 | 시험지와 답안을 받아 맞은 수, 전체 수, 틀린 단어 목록(영단어, 정답 뜻, 고른 뜻)을 돌려준다. 답하지 않은 문제가 있으면 채점하지 않는다. **공용** | FR-15, FR-16 |
| F-04-04 | 일차 시험 결과 반영 | 로직 | 틀린 단어의 오답 횟수 +1, 연속 정답 횟수 0, 오답 목록 등재. 일차를 완료로 기록하고 저장(F-07-01)한다 | FR-17, FR-18, FR-19, FR-26 |
| F-04-05 | 시험 응시 화면 | UI | 문제 1개와 보기 4개를 보여 주고 선택을 받는다. 모두 답하면 제출을 활성화한다. 도중에 나가면 결과를 버린다. **공용 화면 부품** | FR-15, NFR-07 |
| F-04-06 | 채점 결과 화면 | UI | 맞은 수 / 전체와 틀린 단어 목록을 보여 준다. **공용 화면 부품** | FR-16 |
| F-04-07 | 재시험 진입 처리 | UI | 지난 일차 목록에서 암기 완료 이상인 일차를 골라 시험(F-04-05)을 시작한다 | FR-13, FR-19 |

### 3.5 F-05 복습 학습 (SC-06)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|

| F-05-02 | 복습 화면 처리 | UI | 일차 목록에서 하나를 고르면 카드 화면(F-03-03)을 연다. 시험 버튼이 없고 기록을 바꾸지 않는다. 대상이 없으면 안내한다 | FR-20, FR-21 |

### 3.6 F-06 오답 학습·오답 시험 (SC-07)

| ID | 단위 기능 | 구분 | 설명 | 대응 FR |
|----|-----------|------|------|---------|
| F-06-01 | 오답 목록 조회·정렬 | 로직 | 오답 목록에 등재된 단어를 오답 횟수 내림차순, 같으면 단어장 순서로 돌려준다 | FR-22 |
| F-06-02 | 오답 시험 결과 반영 | 로직 | 맞힌 단어는 연속 정답 횟수 +1, 3 이 되면 목록에서 제외. 틀린 단어는 연속 정답 횟수 0, 오답 횟수 +1. 저장(F-07-01)한다 | FR-25, FR-26 |
| F-06-03 | 오답 학습 화면 처리 | UI | 오답 목록 순서로 카드 화면(F-03-03)을 열고, 모두 보면 오답 시험 버튼을 활성화한다. 목록이 비면 안내한다 | FR-22, FR-23, FR-24 |
| F-06-04 | 오답 시험 화면 처리 | UI | 오답 목록 전체로 시험지를 만들어(F-04-02) 응시·결과 화면(F-04-05, F-04-06)을 열고, 제출 시 결과를 반영(F-06-02)한다 | FR-24, FR-25 |

### 3.7 F-07 학습 기록 저장 (SC-08)

| F-07-02 | 기록 복원 | 로직 | 실행 시 저장된 단어장과 학습 기록을 읽는다. 기록이 없으면 초기 상태를 돌려준다 | FR-27, FR-28 |
| F-07-03 | 기록 초기화 | 로직 | 진도와 오답 기록을 모두 지운 초기 상태를 만들고 저장한다 | FR-04 |

| F-07-05 | 기록 오류 알림 | UI | 기록 손상·저장 실패를 사용자에게 알린다 | FR-28 |

## 6. 구현 순서 제안

로직 기능은 UI 없이 테스트할 수 있으므로 먼저 구현한다. 확정은 구현 계획서에서 한다.
