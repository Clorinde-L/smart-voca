### 1.2 재현성

- 무작위(출제·보기 위치·복습 카드·가중 출제)는 `AppSession(rng=...)` / `build_exam(rng=...)` 로 시드를 넣는다 (NFR-04).
- 시각(암기·시험 이력, 날짜별 통계)은 `AppSession(clock=...)` 으로 고정한다.
- 실제 `userdata/` 와 `data/toeic_words.csv` 는 건드리지 않는다. 기본 단어장을 쓰는 테스트는 읽기만 한다.
