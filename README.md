# 스마트 보카 (smart-voca)

토익을 준비하는 대학생을 위한 영단어 암기·시험 **웹 앱**입니다. 단어를 하루 학습량만큼 일차로 나눠 카드로 외우고, 4지선다·단답형·OX 시험으로 확인합니다. 암기·시험 이력은 **SQLite DB**에 남고, 이 이력으로 학습 진척 통계를 계산합니다.

- AI기반프로그래밍 2026-2 기말 과제(단어장 웹 앱) 제출물입니다. 요건 원문: `ai-agent/uploads/2026-final/`
- 언어·프레임워크: Python 3.12, Flask 3.1, 운영 서버 gunicorn, 템플릿 Jinja2 (서버에서 HTML 을 그리는 방식)
- **고른 DB: SQLite** (파일 위치는 환경변수 `DB_PATH`, 학교 서버는 `/data/voca.db`)
- 실행 중 인터넷이 필요 없습니다.

## 주요 기능

| 메뉴 | 하는 일 |
|------|---------|
| 홈 | 오늘의 학습(안 끝낸 가장 앞 일차), 진도, 일차 한눈에, 실력 시험 바로 가기 |
| 일차 | 전체 일차 목록과 일차별 단어. 카드로 외우면(전날 외운 단어·자주 틀린 단어가 섞임) 일차 시험을 볼 수 있습니다 |
| 오답 학습 | 시험에서 틀린 단어를 틀린 횟수 순으로 보고, 오답 시험에서 3번 연속 맞히면 목록에서 빠집니다 |
| 시험 | 실력 시험: 문제 수·방향(영→한, 한→영, 섞기)·형식(4지선다, 단답형, OX)을 고르면 안 본 단어·오래된 단어·자주 틀린 단어가 더 자주 나옵니다 |
| 통계 | 현재 일차, 외운 단어 수/전체, 회차별·날짜별 정답률, 자주 틀리는 단어 상위 10 (모두 DB 이력으로 계산) |
| 단어 관리 | 단어 등록·검색·수정·삭제, CSV 가져오기(추가/바꾸기), 단어장·오답 목록 내보내기 |
| 설정 | 하루 학습량, 복습 카드 수, 시험 기본값(문제 수·방향·형식). DB 에 저장됩니다 |

## 구현한 요구사항 ID

자세한 대응은 요구사항 명세서 §0 "기말 과제 요건 대응" 에 있습니다.

| 구분 | 구현 | 미구현 |
|------|------|--------|
| 단어 등록 (기본) | VOCA-FR-001, 002, 003, 004 | |
| 암기 (기본) | VOCA-FR-011, 012, 013, 014 | |
| 시험 (기본) | VOCA-FR-021, 022, 023, 024, 025, 026 | |
| 학습 진척 통계 (기본) | VOCA-FR-031, 032, 033, 034 | |
| 설정 (도전) | VOCA-FR-061, 062 | |
| 로그인·다른 계정 이력 (도전) | | VOCA-FR-041~043, 051~053 (DB 에 `user_id` 를 두어 나중에 붙일 수 있게 함) |
| 비기능 | VOCA-NFR-001, 002, 003, 004, 005 | |
| 제출 | VOCA-SUB-001~037 (리포 공개·제출 폼은 사용자가 직접) | |

**CSV 가져오기의 중복 처리 (VOCA-FR-003)**: 첫 줄은 `영단어,뜻` 또는 `word,meaning`. 확인 화면에서 고릅니다.
- **추가**: 이미 있는 영단어(대소문자 무시)는 건너뛰고 기존 뜻을 유지합니다. 파일 안에서 겹치면 앞줄만 씁니다.
- **바꾸기**: 지금 단어와 학습 기록을 모두 지우고 파일의 단어로 새로 시작합니다.

## 실행 방법

### 1) 학교 서버 / Docker

리포 루트에서 이미지를 만들고 띄웁니다. 앱은 `0.0.0.0:8080` 에서 듣고, 처음 실행하면 DB 테이블을 만들고 기본 단어장(2,109개)을 넣습니다.

```bash
docker build -t smart-voca .
docker run --rm -p 8080:8080 -e SECRET_KEY=<임의의 긴 문자열> -v voca-data:/data smart-voca
# 브라우저에서 http://localhost:8080/
```

| 환경변수 | 기본값 | 설명 |
|----------|--------|------|
| `DB_PATH` | `/data/voca.db` (이미지), `userdata/voca.db` (로컬) | SQLite 파일 위치 |
| `SECRET_KEY` | 없으면 기동할 때 무작위 | 쿠키 서명 키. 코드·리포에 넣지 않습니다 |

푸시할 때마다 `.github/workflows/docker-check.yml`(과제 배포본, 수정 금지)이 서버와 같은 조건(UID 10001, 인터넷 차단, `/2026/voca-check/` 하위 경로)으로 빌드·실행을 점검합니다.

### 2) 내 PC (Windows)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
.venv\Scripts\python -m smartvoca              # 127.0.0.1:8765 에 서버를 띄우고 브라우저를 엽니다
.venv\Scripts\python -m smartvoca --port 9000  # 포트를 바꿀 때
```

프로젝트 폴더의 **`스마트보카 실행.bat`** 을 더블클릭해도 됩니다. 끝낼 때는 검은 서버 창을 닫습니다. 학습 기록은 `userdata/voca.db` 에 남고, 지우면 처음 상태로 돌아갑니다.

단축키: `←` `→` 이전·다음, `1`~`4` 보기 선택, `O` `X` OX 고르기, `Space` 가린 뜻 보기, `Enter` 다음 단계, `Esc` 뒤로, `Ctrl+F` 단어 검색.

## 테스트

```powershell
.venv\Scripts\python -m pytest
```

로직·DB 저장소·세션·화면 흐름(Flask 테스트 클라이언트)·계층 의존 규칙·배포 규칙(Dockerfile R-01~R-16, 주소 규칙)을 검사합니다.
