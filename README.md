# 스마트 보카 (smart-voca)

토익을 준비하는 대학생을 위한 영단어 암기·시험 프로그램입니다. 토익 빈출 단어 2,000개를 하루 20개씩 100일차로 나눠 외우고, 일차마다 4지선다 시험으로 확인합니다. 틀린 단어는 오답 목록에 모아 따로 학습합니다.

- Windows 11, Python 3.11 이상, PyQt6
- 네트워크 없이 동작하며 학습 기록은 이 PC 에만 저장됩니다.

## 설치

PowerShell 에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

## 실행

프로젝트 폴더의 **`스마트보카 실행.bat`** 을 더블클릭합니다.

터미널에서 실행하려면 다음과 같이 합니다. 시작할 때 오류가 나면 이 방법으로 실행해야 오류 내용이 보입니다.

```powershell
.venv\Scripts\python -m smartvoca
```

## 사용 방법

| 메뉴 | 하는 일 |
|------|---------|
| N일차 학습 시작 | 오늘 일차의 단어 20개를 카드로 봅니다. 모두 보면 시험을 볼 수 있습니다. 시험을 제출하면 다음 일차가 열립니다. |
| 지난 일차 | 이미 학습한 일차를 카드로 복습하거나 시험을 다시 봅니다. |
| 오답 학습 | 시험에서 틀린 단어를 틀린 횟수 순으로 봅니다. 카드를 모두 본 뒤 오답 시험을 볼 수 있고, 3번 연속 맞힌 단어는 목록에서 빠집니다. |
| 단어 목록 | 다른 단어장(CSV)을 불러오거나, 단어장과 오답 목록을 CSV 로 내보냅니다. |

단축키: `←` `→` 이전·다음, `1`~`4` 보기 선택, `Space` 가린 뜻 보기, `Enter` 다음 단계, `Esc` 뒤로.

카드 화면에서 `뜻 가리고 외우기`를 켜면 영단어만 먼저 보고 뜻을 떠올린 뒤 확인할 수 있습니다. 시험 화면에서는 위쪽의 문제 번호 점을 눌러 원하는 문제로 바로 갈 수 있습니다.

### 단어장 CSV 형식

첫 줄은 `word,meaning`, 그 아래로 한 줄에 영단어 하나와 뜻 하나를 씁니다. UTF-8 로 저장하고, 뜻에 쉼표가 있으면 큰따옴표로 감쌉니다. 단어는 4개 이상이어야 하고 중복될 수 없습니다.

```csv
word,meaning
agenda,"[명] 안건, 의제; 일정표"
```

**다른 단어장을 불러오면 학습 기록이 모두 지워집니다.** 기본 단어장으로 되돌리려면 `data/toeic_words_2000.csv` 를 불러오면 됩니다.

## 데이터 위치

| 경로 | 내용 |
|------|------|
| `data/toeic_words_2000.csv` | 기본 단어장. 프로그램은 읽기만 합니다. |
| `userdata/progress.json` | 학습 기록. 지우면 처음 상태로 돌아갑니다. |
| `userdata/wordbook.csv` | 불러온 단어장의 사본. |

## 폴더 구조

```
src/smartvoca/
├── core/      도메인 로직 (진도, 카드, 시험, 오답) — 표준 라이브러리만 사용
├── storage/   단어장 CSV, 학습 기록 JSON
├── session.py 화면이 쓰는 창구 (로직 호출 순서와 저장 시점 관리)
└── ui/        PyQt6 화면
tests/         pytest
docs/          승인된 기획·분석·설계 문서
ai-agent/claude/  작업 계획, 일지
```

분석·설계 문서는 `docs/` 의 `분석_261111_*`, `설계_261111_*` 를 참고하세요.
