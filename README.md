# 스마트 보카 (smart-voca)

토익을 준비하는 대학생을 위한 영단어 암기·시험 프로그램입니다. 토익 빈출 단어 2,109개를 하루 20개씩 106일차로 나눠 외우고, 일차마다 4지선다 시험으로 확인합니다. 틀린 단어는 오답 목록에 모아 따로 학습합니다.

- Windows 11, Python 3.11 이상, Flask. 화면은 웹 브라우저(Edge, Chrome 등)에서 봅니다.
- 프로그램이 내 PC 안에서만 도는 작은 웹 서버(`http://127.0.0.1:8765/`)를 띄웁니다. 인터넷 연결이 필요 없고, 다른 PC·휴대폰에서는 접속할 수 없습니다.
- 학습 기록은 이 PC 에만 저장됩니다.

## 설치

PowerShell 에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

## 실행

프로젝트 폴더의 **`스마트보카 실행.bat`** 을 더블클릭합니다. 검은 서버 창이 뜨고 잠시 뒤 브라우저에 스마트 보카가 열립니다.

- **끝낼 때는 검은 서버 창을 닫습니다.** 브라우저 탭만 닫으면 서버는 계속 돌고 있으며, `http://127.0.0.1:8765/` 로 다시 들어갈 수 있습니다.
- 이미 실행 중일 때 다시 실행하면 서버를 하나 더 띄우지 않고 브라우저만 엽니다.
- 시험 도중 서버 창을 닫으면 그 시험은 없던 것이 됩니다(기록에 반영되지 않음).

터미널에서 실행하려면 다음과 같이 합니다.

```powershell
.venv\Scripts\python -m smartvoca              # 브라우저가 자동으로 열림
.venv\Scripts\python -m smartvoca --port 9000  # 8765 포트를 다른 프로그램이 쓰고 있을 때
.venv\Scripts\python -m smartvoca --no-browser # 브라우저를 열지 않음
```

## 사용 방법

| 메뉴 | 하는 일 |
|------|---------|
| N일차 학습 시작 | 오늘 일차의 단어 20개를 카드로 봅니다. 모두 보면 시험을 볼 수 있습니다. 시험을 제출하면 다음 일차가 열립니다. |
| 지난 일차 | 이미 학습한 일차를 카드로 복습하거나 시험을 다시 봅니다. |
| 오답 학습 | 시험에서 틀린 단어를 틀린 횟수 순으로 봅니다. 카드를 모두 본 뒤 오답 시험을 볼 수 있고, 3번 연속 맞힌 단어는 목록에서 빠집니다. |
| 단어 목록 | 전체 단어를 검색하고, 다른 단어장(CSV)을 불러오거나 단어장과 오답 목록을 CSV 로 내보냅니다. 내보낸 파일은 브라우저의 다운로드 폴더에 저장됩니다. |

단축키: `←` `→` 이전·다음, `1`~`4` 보기 선택, `Space` 가린 뜻 보기, `Enter` 다음 단계, `Esc` 뒤로, `Ctrl+F` 단어 검색(단어 목록 화면).

카드 화면에서 `뜻 가리고 외우기`를 켜면 영단어만 먼저 보고 뜻을 떠올린 뒤 확인할 수 있습니다. 시험 화면에서는 위쪽의 문제 번호 점을 눌러 원하는 문제로 바로 갈 수 있습니다.

### 단어장 CSV 형식

첫 줄은 `word,meaning`, 그 아래로 한 줄에 영단어 하나와 뜻 하나를 씁니다. UTF-8 로 저장하고, 뜻에 쉼표가 있으면 큰따옴표로 감쌉니다. 단어는 4개 이상이어야 하고 중복될 수 없습니다.

```csv
word,meaning
agenda,"[명] 안건, 의제; 일정표"
```

**다른 단어장을 불러오면 학습 기록이 모두 지워집니다.** 기본 단어장으로 되돌리려면 `data/toeic_words.csv` 를 불러오면 됩니다.

## 데이터 위치

| 경로 | 내용 |
|------|------|
| `data/toeic_words.csv` | 기본 단어장. 프로그램은 읽기만 합니다. |
| `userdata/progress.json` | 학습 기록. 지우면 처음 상태로 돌아갑니다. |
| `userdata/wordbook.csv` | 불러온 단어장의 사본. |

## 테스트

```powershell
.venv\Scripts\python -m pytest
```

로직·저장·세션 테스트와 함께, 웹 화면 흐름 테스트(`tests/test_web_flow.py`)가 브라우저 없이 Flask 테스트 클라이언트로 돕니다.

## 폴더 구조

```
src/smartvoca/
├── core/      도메인 로직 (진도, 카드, 시험, 오답) — 표준 라이브러리만 사용
├── storage/   단어장 CSV, 학습 기록 JSON
├── session.py 화면이 쓰는 창구 (로직 호출 순서와 저장 시점 관리)
└── web/       웹 화면 (Flask): app.py 라우트, state.py 진행 중인 카드·시험, templates/, static/
tests/         pytest
docs/          승인된 기획·분석·설계 문서
ai-agent/claude/  작업 계획, 일지
```

분석·설계 문서는 `docs/` 의 `분석_261111_*`, `설계_261111_*` 를 참고하세요.
